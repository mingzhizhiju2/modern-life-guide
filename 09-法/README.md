## 核心原则

- **证据为王**：任何法律纠纷，证据是第一位的
- **不要私了**：重大权益问题，咨询专业人士
- **了解底线**：不需要成为法律专家，但要知道自己的底线在哪里
- **法律援助**：经济困难可以申请法律援助
