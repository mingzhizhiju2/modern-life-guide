# 劳动权益

> **一句话核心：** 了解自己的劳动权益，不是和公司对抗，而是保护自己。

## 适用人群

- 刚入职场的年轻人
- 对工资、加班、休假有疑问的人
- 正在考虑离职或被裁员的人

## 劳动合同

### 必备条款

根据《劳动合同法》，劳动合同必须包含：

| 条款 | 说明 |
|------|------|
| 用人单位信息 | 名称、地址、法定代表人 |
| 劳动者信息 | 姓名、身份证号 |
| 合同期限 | 固定期限、无固定期限、以完成一定工作为期限 |
| 工作内容 | 岗位、职责、工作地点 |
| 工作时间 | 标准工时、不定时、综合计算 |
| 劳动报酬 | 工资标准、支付方式、支付时间 |
| 社会保险 | 五险一金 |
| 劳动保护 | 劳动条件、职业危害防护 |

### 试用期

| 合同期限 | 试用期上限 |
|---------|-----------|
| 3 个月以上不满 1 年 | 1 个月 |
| 1 年以上不满 3 年 | 2 个月 |
| 3 年以上 | 6 个月 |
| 以完成一定工作任务为期限 | 不得约定试用期 |

> 试用期工资不得低于同岗位工资的 80% 或劳动合同约定工资的 80%。

## 工资

### 最低工资

- 各地标准不同，每年调整
- 试用期工资不低于最低工资
- 加班费计算基数不低于最低工资

### 加班费

| 加班类型 | 加班费标准 | 说明 |
|---------|-----------|------|
| 工作日加班 | 150% 工资 | 超过 8 小时的部分 |
| 休息日加班 | 200% 工资 | 不能补休的 |
| 法定节假日加班 | 300% 工资 | 春节、国庆等 |

### 工资支付

- 按月支付，不得克扣
- 工资条应包含：应发工资、扣除项目、实发工资
- 离职时结清工资

## 休假

### 法定节假日

| 节日 | 天数 |
|------|------|
| 元旦 | 1 天 |
| 春节 | 3 天 |
| 清明节 | 1 天 |
| 劳动节 | 1 天 |
| 端午节 | 1 天 |
| 中秋节 | 1 天 |
| 国庆节 | 3 天 |

### 年假

| 工作年限 | 年假天数 |
|---------|---------|
| 满 1 年不满 10 年 | 5 天 |
| 满 10 年不满 20 年 | 10 天 |
| 满 20 年 | 15 天 |

### 其他假期

| 假期类型 | 天数 | 说明 |
|---------|------|------|
| 婚假 | 3 天（各地不同） | 晚婚奖励假各地不同 |
| 产假 | 98 天 + 地方奖励 | 难产、多胞胎增加 |
| 陪产假 | 7-30 天（各地不同） | 父亲 |
| 病假 | 根据工龄 | 需医院证明 |
| 丧假 | 1-3 天 | 直系亲属去世 |

## 离职

### 主动辞职

| 情况 | 通知期 | 说明 |
|------|--------|------|
| 试用期 | 3 天 | 不需要公司批准 |
| 正式员工 | 30 天 | 书面通知，不需要公司批准 |

### 被辞退

| 情况 | 补偿 | 说明 |
|------|------|------|
| 协商一致 | N | N = 工作年限（每满 1 年赔 1 个月） |
| 无过失辞退 | N+1 | 提前 30 天通知就不用 N+1 |
| 违法辞退 | 2N | 可以要求继续履行合同 |
| 经济性裁员 | N | 公司经营困难 |

### 经济补偿金计算

```
N = 工作年限（满半年算 1 年，不满半年算 0.5 年）
月工资 = 离职前 12 个月平均工资（上限为当地社平工资 3 倍）
```

## 劳动仲裁

### 流程

1. 协商（向公司提出诉求）
2. 调解（劳动监察大队调解）
3. 仲裁（劳动仲裁委员会）
4. 诉讼（法院）

### 仲裁注意事项

| 事项 | 说明 |
|------|------|
| 时效 | 离职后 1 年内申请 |
| 证据 | 劳动合同、工资条、考勤记录、聊天记录 |
| 费用 | 劳动仲裁免费 |
| 结果 | 不服可起诉到法院 |
