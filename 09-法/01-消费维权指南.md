# 消费维权指南

> **一句话核心：** 消费者不是弱势群体，只是很多人不知道自己的权利。

## 适用人群

- 买到假货/次品不知道怎么维权的人
- 被商家拒绝退款/退货的人
- 想了解消费者权益的人

## 消费者有哪些权利

根据《消费者权益保护法》，消费者享有以下权利：

| 权利 | 说明 |
|------|------|
| 安全权 | 人身和财产安全不受损害 |
| 知情权 | 了解商品/服务的真实情况 |
| 选择权 | 自主选择商品/服务 |
| 公平交易权 | 公平交易、拒绝强制交易 |
| 求偿权 | 受到损害时获得赔偿 |
| 结社权 | 依法成立消费者组织 |
| 获知权 | 获得消费知识 |
| 受尊重权 | 人格尊严、民族风俗受尊重 |
| 监督权 | 对商品/服务进行监督 |

## 维权流程

### 第一步：保留证据

| 证据类型 | 说明 |
|---------|------|
| 购物凭证 | 发票、收据、订单截图、支付记录 |
| 商品证据 | 商品实物照片/视频、包装 |
| 沟通记录 | 和商家的聊天记录、通话录音 |
| 鉴定报告 | 需要鉴定的商品（如珠宝、食品） |

### 第二步：沟通协商

1. 联系商家客服，说明问题
2. 提出合理诉求（退款、换货、赔偿）
3. 保留沟通记录
4. 商家拒绝或拖延，进入下一步

### 第三步：投诉渠道

| 渠道 | 方式 | 处理范围 |
|------|------|---------|
| 12315 | 电话、网站、APP、小程序 | 所有消费纠纷 |
| 平台投诉 | 淘宝、京东、拼多多等平台客服 | 平台内交易 |
| 12345 | 市民服务热线 | 各类投诉 |
| 行业主管部门 | 食药监、工商局等 | 行业问题 |

### 第四步：法律途径

| 途径 | 说明 | 成本 |
|------|------|------|
| 调解 | 消费者协会、市场监管局调解 | 免费 |
| 仲裁 | 双方协商一致可仲裁 | 收费 |
| 诉讼 | 法院起诉 | 收费（小额诉讼成本低） |

## 常见消费纠纷处理

### 网购退货

| 情况 | 能否退货 | 规定 |
|------|---------|------|
| 7 天无理由 | 可以 | 除特殊商品（生鲜、定制、在线下载等） |
| 商品质量问题 | 任何时候 | 商家承担运费 |
| 超过 7 天 | 不一定 | 需要商品有质量问题 |

### 食品安全问题

| 问题 | 赔偿标准 |
|------|---------|
| 食品过期/变质 | 损失 + 10 倍赔偿（不足 1000 元按 1000 元赔） |
| 食品中有异物 | 同上 |
| 虚假宣传 | 退一赔三 |

### 预付费/充值卡

| 问题 | 解决方法 |
|------|---------|
| 商家跑路 | 收集证据，向市场监管局投诉 |
| 余额不退 | 要求退还余额 |
| 服务缩水 | 要求按原约定履行 |

## 投诉实用技巧

1. **12315 投诉**：说清楚时间、地点、商家、问题、诉求
2. **保留证据**：发票、聊天记录、商品照片
3. **态度坚定**：有理有据，不要被商家拖延
4. **联合维权**：同样问题的消费者可以联合起来
5. **媒体曝光**：重大消费问题可以找媒体曝光
