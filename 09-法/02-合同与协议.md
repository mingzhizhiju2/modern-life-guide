# 合同与协议

> **一句话核心：** 合同是保护自己的工具，不是走过场的形式。

## 适用人群

- 签合同经常不看条款的人
- 在租房、买房、工作中签过合同的人
- 想了解合同陷阱的人

## 合同审查要点

### 通用审查清单

| 项目 | 审查要点 |
|------|---------|
| 双方信息 | 名称、地址、联系方式是否完整准确 |
| 合同标的 | 商品/服务的内容、数量、质量标准 |
| 价格 | 金额、支付方式、支付时间、发票 |
| 履行期限 | 开始时间、截止时间、交付方式 |
| 违约责任 | 违约情形、违约金比例、赔偿范围 |
| 争议解决 | 仲裁还是诉讼、管辖地 |
| 变更解除 | 变更条件、解除条件 |
| 保密条款 | 保密范围、保密期限（如有） |
| 签字盖章 | 确认签字人有权代表公司 |

### 重点注意的条款

| 条款 | 注意 |
|------|------|
| 免责条款 | 哪些情况对方不负责？是否合理？ |
| 不可抗力 | 定义是否过宽？（如"政策变化"） |
| 自动续约 | 不通知就自动续约的条款 |
| 争议管辖 | 是否约定在对方所在地法院（增加你的维权成本） |
| 格式条款 | 提供方免除自己责任的条款可能无效 |

## 常见合同陷阱

### 劳动合同陷阱

| 陷阱 | 说明 | 应对 |
|------|------|------|
| 空白合同 | 工资、岗位等关键信息留空 | 拒绝签署 |
| 不签合同 | 口头约定 | 要求签订正式合同 |
| 试用期过长 | 劳动合同期限对应的试用期上限 | 了解法律规定 |
| 扣押证件 | 扣押身份证、毕业证 | 拒绝，这是违法的 |
| 违约金陷阱 | 不合理的违约金条款 | 除培训费外，不得约定违约金 |

### 租赁合同陷阱

| 陷阱 | 说明 | 应对 |
|------|------|------|
| 转租未告知 | 二房东转租未经大房东同意 | 要求查看房产证和租赁合同 |
| 押金不退还 | 退租时以各种理由扣押金 | 入住时拍照留证 |
| 维修责任不清 | 家电坏了谁负责修 | 明确维修责任划分 |
| 提前解约 | 违约金过高 | 约定合理的违约金 |

### 消费合同陷阱

| 陷阱 | 说明 | 应对 |
|------|------|------|
| 预付卡 | 充钱后商家跑路 | 控制充值金额 |
| 自动续费 | 试用期后自动扣费 | 取消自动续费 |
| 最终解释权 | "本公司拥有最终解释权" | 该条款无效 |

## 电子合同

### 电子合同的法律效力

- 电子合同和纸质合同具有同等法律效力
- 需要可靠的电子签名
- 电子合同签署后不可篡改

### 电子合同注意事项

| 注意 | 说明 |
|------|------|
| 确认签署主体 | 电子签名是否真实有效 |
| 保存合同 | 下载 PDF 版本保存 |
| 确认平台 | 使用正规电子合同平台 |

## 合同签署注意事项

1. **不要签空白合同**：任何空白处都要填写完整
2. **修改需双方确认**：修改处要双方签字或盖章
3. **保留合同原件**：双方各执一份
4. **口头承诺不算数**：所有承诺都要写在合同里
5. **不懂就问**：不明白的条款咨询专业人士
