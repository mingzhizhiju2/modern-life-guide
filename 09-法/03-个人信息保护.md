# 个人信息保护

> **一句话核心：** 个人信息是你最重要的数字资产，要像保护钱包一样保护它。

## 适用人群

- 担心个人信息泄露的人
- 经常收到骚扰电话/短信的人
- 想提高数字安全意识的人

## 个人信息包括什么

| 类别 | 内容 |
|------|------|
| 基本身份信息 | 姓名、身份证号、住址、电话 |
| 生物识别信息 | 指纹、面部特征、声纹 |
| 网络身份信息 | 账号、密码、IP 地址 |
| 健康信息 | 病历、体检报告、基因信息 |
| 金融信息 | 银行卡号、交易记录、征信 |
| 位置信息 | 精确位置、行踪轨迹 |
| 通讯信息 | 通讯录、通话记录、短信 |

## 个人信息泄露的常见途径

| 途径 | 说明 | 防范方法 |
|------|------|---------|
| 网络注册 | 注册各种 APP 和网站 | 最小化授权，不必要的信息不填 |
| 快递单 | 姓名、电话、地址 | 撕掉或涂黑后再扔 |
| 问卷调查 | 街边/网上的调查 | 不提供真实信息 |
| 公共 Wi-Fi | 不安全的网络 | 不用公共 Wi-Fi 处理敏感信息 |
| 社会工程 | 冒充客服/熟人套取信息 | 先核实对方身份 |
| 数据泄露 | 平台数据被黑客窃取 | 不同平台用不同密码 |

## 日常防范措施

### 手机设置

| 设置 | 建议 |
|------|------|
| 锁屏密码 | 设置复杂密码/指纹/面部识别 |
| APP 权限 | 关闭不必要的权限（如手电筒不需要位置） |
| 相册权限 | 限制 APP 读取相册 |
| 广告追踪 | 关闭"允许 APP 请求跟踪" |
| 蓝牙/Wi-Fi | 不用时关闭 |

### 账号安全

| 建议 | 说明 |
|------|------|
| 不同密码 | 每个平台用不同密码 |
| 密码强度 | 大写+小写+数字+符号，12 位以上 |
| 两步验证 | 开启双重认证 |
| 密码管理器 | 用 Bitwarden 等工具管理密码 |
| 定期更换 | 每 3-6 个月更换重要账号密码 |

### 网络使用

| 场景 | 建议 |
|------|------|
| 公共 Wi-Fi | 不使用，或用 VPN |
| 陌生链接 | 不点击 |
| 二维码 | 不扫描来历不明的二维码 |
| 钓鱼邮件 | 不点击不明链接，不下载附件 |
| 屏幕共享 | 不和不信任的人共享屏幕 |

## 被侵权后的应对

### 信息泄露后

1. 修改相关账号密码
2. 通知银行冻结账户（如涉及金融信息）
3. 报警（如涉及诈骗）
4. 向平台投诉（要求删除信息）

### 骚扰电话/短信

| 方式 | 说明 |
|------|------|
| 拉黑 | 拉黑号码 |
| 举报 | 12321 网络不良与垃圾信息举报 |
| 防骚扰 | 开启手机防骚扰功能 |
| 不要回复 | 回复"退订"可能确认号码有效 |

## 法律保护

### 《个人信息保护法》核心要点

- 收集个人信息需要**告知并取得同意**
- 不得过度收集信息（和业务无关的信息不能收集）
- 个人有权**查阅、复制、更正、删除**自己的信息
- 个人信息泄露时，平台有义务**通知用户**
- 侵犯个人信息可要求**赔偿损失**

### 维权途径

| 问题 | 途径 |
|------|------|
| 平台违规收集信息 | 向网信办投诉 |
| 个人信息被泄露 | 报警 |
| 骚扰电话/短信 | 12321 举报 |
| 法律纠纷 | 法院起诉 |
