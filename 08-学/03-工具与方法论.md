# 工具与方法论

> **一句话核心：** 工具的意义在于帮助你建立系统，而不是增加你的复杂度。

## 适用人群

- 想提高工作/学习效率的人
- 工具控（总在找更好的工具）的人
- 想建立个人知识管理系统的人

## 时间管理

### 番茄工作法

| 步骤 | 说明 |
|------|------|
| 1 | 选择一个任务 |
| 2 | 设定 25 分钟计时器 |
| 3 | 专注工作，直到计时器响 |
| 4 | 休息 5 分钟 |
| 5 | 每 4 个番茄钟，休息 15-30 分钟 |

**要点：**
- 一个番茄钟不可分割
- 如果中途被打断，番茄钟作废
- 不要用番茄钟做"开始"的工作，做"持续"的工作

### 重要-紧急四象限

|  | 紧急 | 不紧急 |
|--|------|--------|
| **重要** | 立即做 | 计划做 |
| **不重要** | 委托别人 | 不要做 |

### 每日计划

1. 前一天晚上或当天早上列出任务
2. 按优先级排序
3. 预估每项任务的时间
4. 留出缓冲时间（至少 30%）
5. 完成一项划掉一项

## 知识管理

### 知识管理流程

```
收集 → 整理 → 输出 → 复习
```

### 推荐工具

| 用途 | 工具推荐 |
|------|---------|
| 笔记 | Obsidian、Notion、飞书文档、印象笔记 |
| 待办事项 | Todoist、Microsoft To Do、滴答清单 |
| 思维导图 | XMind、幕布、ProcessOn |
| 文件管理 | 本地文件夹、OneDrive、iCloud |

### 笔记方法

**PARA 法：**
- **P（Projects）**：正在进行的项目
- **A（Areas）**：长期负责的领域
- **R（Resources）**：未来可能用到的资料
- **A（Archives）**：已完成/不活跃的内容

**卡片笔记法：**
- 每张卡片记录一个独立的想法
- 用链接建立卡片之间的关联
- 适合 Obsidian、Roam Research

## 阅读方法

### 精读 vs 泛读

| 方式 | 适用场景 | 方法 |
|------|---------|------|
| 泛读 | 了解概览、筛选信息 | 快速浏览、抓关键词 |
| 精读 | 深入学习、理解核心 | 逐字阅读、做笔记、思考 |

### 主题阅读

1. 确定一个主题
2. 找到 3-5 本相关书籍
3. 快速浏览目录，找到相关章节
4. 对比不同作者的观点
5. 形成自己的理解

## 写作方法

### 写作流程

1. **确定主题和读者**
2. **收集素材**
3. **列出提纲**
4. **写初稿**（不要边写边改）
5. **修改**（内容、结构、语言）
6. **校对**（错别字、标点）

### 实用写作技巧

- **先写再改**：初稿和修改分开
- **KISS 原则**：Keep It Simple, Stupid
- **多用短句**：一句话说清楚一个意思
- **用例子**：抽象概念配具体例子
