# 技能学习路径

> **一句话核心：** 学会任何技能的核心公式：明确目标 + 优质资源 + 刻意练习 + 持续反馈。

## 适用人群

- 想学新技能但不知道从何入手的人
- 觉得学不会、学不进去的人
- 想提高学习效率的人

## 学习方法论

### 费曼学习法

1. **选择一个概念**：确定你要学什么
2. **教给别人**：用最简单的话解释给一个不懂的人听
3. **发现盲点**：在解释过程中发现自己的知识漏洞
4. **回顾补充**：回到资料中填补漏洞
5. **简化类比**：用更简单的语言和类比重新解释

### 刻意练习

| 原则 | 说明 |
|------|------|
| 明确目标 | 每次练习有具体目标 |
| 专注 | 全身心投入，不分心 |
| 反馈 | 及时知道对错 |
| 突破舒适区 | 练习难度略高于当前水平 |
| 重复 | 大量重复，直到形成肌肉记忆 |

### 间隔重复

- 学习新知识后，在以下时间复习：
  - 1 天后
  - 3 天后
  - 7 天后
  - 14 天后
  - 30 天后
- 推荐工具：Anki、SuperMemo

## 制定学习计划

### SMART 目标

| 要素 | 说明 | 示例（学英语） |
|------|------|-------------|
| S（具体） | 明确要学什么 | 每天背 20 个单词 |
| M（可衡量） | 可以量化进度 | 每周测试正确率 |
| A（可达成） | 在能力范围内 | 每天 30 分钟 |
| R（相关） | 和你的目标相关 | 和工作/考试相关 |
| T（有时限） | 设定期限 | 3 个月后达到四级水平 |

### 100 小时入门法

大多数技能，100 小时的刻意练习可以让你达到"能用的水平"：

| 技能 | 100 小时能达到的水平 |
|------|--------------------|
| 一门语言 | 简单日常对话 |
| 编程 | 能写简单程序 |
| 乐器 | 能弹奏简单曲子 |
| 绘画 | 能画出基本准确的东西 |
| 烹饪 | 能做一桌家常菜 |

## 常见学习误区

1. **"收藏等于学会"**
   - 收藏夹里的资料 90% 不会再看第二次

2. **"完美准备再开始"**
   - 先开始，再完善，边做边学

3. **"同时学多个技能"**
   - 一次专注一个技能，入门后再学下一个

4. **"只输入不输出"**
   - 最好的学习方式是教给别人

5. **"和别人比进度"**
   - 学习不是比赛，按自己的节奏来
