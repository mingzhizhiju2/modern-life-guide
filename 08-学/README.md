## 核心原则

- **学会辨别**：在信息爆炸的时代，辨别真伪是第一能力
- **学会学习**：比学知识更重要的是学习方法
- **学会说不**：对营销话术、消费陷阱说"不"
- **学会思考**：不盲从、不轻信、独立思考

## 贡献方向

- 补充不同领域的入门学习路径
- 增加常见逻辑谬误的识别方法
- 增加深度伪造（AI造假）内容的识别技巧
