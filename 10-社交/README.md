## 核心原则

- **真诚＞技巧**：社交技巧是锦上添花，真诚是基础
- **边界感**：好的关系都需要边界
- **质量＞数量**：几个好朋友比一百个点头之交更有价值
- **互相尊重**：不委屈自己，不强迫他人
