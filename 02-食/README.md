## 核心原则

- **新鲜优先**：加工越少的食物通常越健康
- **看懂标签**：配料表按含量排序，前三名决定本质
- **适度烹饪**：不同烹饪方式对营养的保留差异很大
- **不迷信"纯天然"**：天然≠安全，加工≠有害
