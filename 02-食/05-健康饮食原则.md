# 健康饮食原则

> **一句话核心：** 没有"神奇食物"，平衡多样才是健康饮食的真谛。

## 适用人群

- 想吃得健康但不知道从何入手的人
- 被各种"超级食物""排毒食谱"困扰的人
- 有减脂、增肌等特殊目标的人

## 中国居民膳食指南（2022）核心建议

> 来源：中国营养学会

### 平衡膳食八准则

1. **食物多样，合理搭配**
2. **吃动平衡，健康体重**
3. **多吃蔬果、奶类、全谷、大豆**
4. **适量吃鱼、禽、蛋、瘦肉**
5. **少盐少油，控糖限酒**
6. **规律进餐，足量饮水**
7. **会烹会选，会看标签**
8. **公筷分餐，杜绝浪费**

### 每日推荐摄入量

| 食物类别 | 推荐量 | 备注 |
|---------|--------|------|
| 谷薯类 | 250-400g | 全谷物和杂豆占 50-150g |
| 蔬菜 | 300-500g | 深色蔬菜占一半 |
| 水果 | 200-350g | 不要用果汁代替 |
| 动物性食品 | 120-200g | 鱼/禽/蛋/瘦肉 |
| 奶及奶制品 | 300-500g | 或等量酸奶/奶酪 |
| 大豆及坚果 | 25-35g | 坚果约一小把 |
| 盐 | <5g | 包括酱油等调味品中的盐 |
| 油 | 25-30g | 多种植物油轮换用 |
| 水 | 1500-1700ml | 约 7-8 杯 |

## 常见饮食误区

### 误区 1：减肥就不吃主食

- 碳水化合物是身体的主要能量来源
- 可以用全谷物、杂豆、薯类替代精米白面
- 完全不吃主食会导致代谢紊乱

### 误区 2：蛋黄不能吃，胆固醇高

- 膳食胆固醇对血液胆固醇的影响被高估了
- 蛋黄富含卵磷脂、维生素 D
- 正常人每天 1-2 个鸡蛋完全没问题

### 误区 3：超级食物有神奇功效

- 牛油果、奇亚籽、藜麦等"超级食物"确实有营养
- 但没有任何一种食物是不可替代的
- 很多本土食物（小米、燕麦、豆类）营养价值同样出色

### 误区 4：果汁比水果健康

- 榨汁破坏了膳食纤维
- 一杯果汁往往需要多个水果，糖分超标
- 喝果汁升糖速度远快于吃水果

## 不同目标下的饮食调整

### 减脂

| 原则 | 说明 |
|------|------|
| 热量缺口 | 每日摄入比消耗少 300-500 千卡 |
| 高蛋白 | 增加饱腹感，减少肌肉流失 |
| 控糖限油 | 减少精制糖和油炸食品 |
| 多喝水 | 帮助代谢，减少饥饿感 |

### 增肌

| 原则 | 说明 |
|------|------|
| 热量盈余 | 每日摄入比消耗多 200-300 千卡 |
| 足量蛋白 | 每公斤体重 1.6-2.2g 蛋白质 |
| 练后补充 | 运动后 1 小时内补充蛋白质+碳水 |
| 充足睡眠 | 肌肉在休息时生长 |

### 控糖/糖尿病

| 原则 | 说明 |
|------|------|
| 低 GI 饮食 | 选择升糖指数低的食物 |
| 定时定量 | 规律进餐，不过饥过饱 |
| 先菜后饭 | 先吃蔬菜和蛋白质，再吃主食 |
| 控制总量 | 碳水化合物总量比种类更重要 |
