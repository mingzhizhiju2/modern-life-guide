# 食品安全常识

> **一句话核心：** 食品安全的第一原则是"温度"和"时间"的管理。

## 适用人群

- 经常做饭但不确定食物是否安全的人
- 对食物保存和保质期有困惑的人
- 家里有老人小孩等敏感人群的人

## 保质期解读

| 标注 | 含义 |
|------|------|
| 保质期至 XXXX 年 XX 月 XX 日 | 在此日期前食用品质最佳 |
| 生产日期 + 保质期 X 个月 | 需要自己计算到期日 |
| 在此日期前食用最佳 | 过期的食物不一定变质，但品质下降 |
| 开封后 X 天内食用 | 开封后保质期重新计算 |

### 不同食品的安全期限

| 食品类别 | 未开封保质期 | 开封后保质期 |
|---------|-------------|-------------|
| 牛奶（巴氏） | 7-15 天 | 2-3 天 |
| 牛奶（常温） | 6-12 个月 | 2-3 天 |
| 鸡蛋 | 30 天 | 30 天（冷藏） |
| 食用油 | 18-24 个月 | 3-6 个月 |
| 酱油 | 18-24 个月 | 6-12 个月 |
| 大米 | 6-12 个月 | 6-12 个月 |
| 冷冻肉 | 6-12 个月 | 3-6 个月 |

## 食物中毒预防

### 常见食物中毒原因

| 原因 | 常见食物 | 症状 | 潜伏期 |
|------|---------|------|--------|
| 沙门氏菌 | 生鸡蛋、鸡肉 | 腹泻、呕吐、发热 | 6-72 小时 |
| 大肠杆菌 | 未煮熟的牛肉、生菜 | 血性腹泻、腹痛 | 1-10 天 |
| 金黄色葡萄球菌 | 剩饭剩菜、奶油蛋糕 | 剧烈呕吐、腹泻 | 1-6 小时 |
| 肉毒杆菌 | 自制罐头、真空包装食品 | 神经麻痹、呼吸困难 | 12-72 小时 |
| 黄曲霉毒素 | 发霉的花生、玉米 | 肝损伤（慢性） | 长期 |

### 预防原则

1. **保持清洁**：勤洗手、清洗厨具
2. **生熟分开**：生肉和熟食用不同的砧板、刀具
3. **彻底煮熟**：中心温度达到 70℃ 以上
4. **安全温度**：熟食在室温下不超过 2 小时
5. **安全水源**：使用安全的水和食材

## 食品储存温度指南

| 温度区间 | 安全情况 | 说明 |
|---------|---------|------|
| 60℃ 以上 | 安全 | 热食保温区，细菌难以生长 |
| 4-60℃ | **危险区** | 细菌快速繁殖，食物在此区间不超过 2 小时 |
| 0-4℃ | 冷藏安全区 | 大多数细菌生长缓慢 |
| -18℃ 以下 | 冷冻安全区 | 细菌停止生长，但不死亡 |

## 常见食品安全误区

1. **"发霉的食物，把霉点切掉就能吃"**
   - 霉菌的菌丝可能已经扩散到整个食物，肉眼看不到
   - 软质食物（面包、水果、酸奶）发霉直接扔掉
   - 硬质食物（硬奶酪、硬火腿）切掉霉点周围 2.5cm 以上

2. **"食物没异味就是安全的"**
   - 大多数致病菌不产生异味
   - 不能靠闻来判断是否安全

3. **"冰箱是保险箱"**
   - 冰箱不能杀死细菌，只能减缓生长
   - 定期清理冰箱，检查过期食品

4. **"热水烫一下就能消毒"**
   - 短时间热水冲洗不能杀死大部分细菌
   - 需要 70℃ 以上持续加热

## 厨房卫生要点

1. **砧板**：建议备两块，生熟分开
2. **抹布**：每周更换或煮沸消毒
3. **冰箱**：每月清理一次，温度设置在 4℃ 以下
4. **垃圾桶**：带盖、每天清理
