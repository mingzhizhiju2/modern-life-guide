# 配料表解读指南

> **一句话核心：** 配料表是食品最诚实的自我介绍——按含量从高到低排序。

## 适用人群

- 想吃得健康但不知道怎么看标签的人
- 被"健康""无添加"等宣传词迷惑的人
- 有特殊饮食需求（控糖、减脂、过敏）的人

## 配料表怎么看

### 黄金法则

1. **按含量排序**：配料按加入量从多到少排列，前几项决定了这个食品的本质
2. **名称越短越好**：配料表越短，加工程度越低
3. **名字越简单越好**：看不懂的化学名称通常是添加剂

### 实操示例

**示例 1：某"全麦面包"配料表**

```
小麦粉、水、白砂糖、人造黄油、全麦粉（5%）、酵母、食盐、面包改良剂……
```

> ⚠️ 全麦粉排在第 5 位，说明全麦成分很少，本质是白面包加了一点全麦粉。真正的全麦面包，全麦粉应该排在前两位。

**示例 2：某"果汁饮料"配料表**

```
水、白砂糖、苹果浓缩汁、柠檬酸、食用香精、维生素C
```

> ⚠️ 果汁含量可能很低，本质是糖水。真正的果汁，果汁含量应在 100% 或配料表第一项是纯果汁。

## 营养成分表解读

### 核心指标

| 项目 | 含义 | 参考值 |
|------|------|--------|
| 能量 | 每份提供的能量 | 成人每日约 2000 千卡（8400 千焦） |
| 蛋白质 | 营养核心 | NRV% 越高越好 |
| 脂肪 | 特别是饱和脂肪和反式脂肪 | 越低越好 |
| 碳水化合物 | 包括糖 | 注意"糖"的含量 |
| 钠 | 盐分 | 每日上限 2000mg |

### 特别关注

**反式脂肪：**
- 即使标注为"0"，如果配料表有"氢化植物油""起酥油"等，仍可能含有少量反式脂肪
- 国家标准：≤0.3g/100g 可标注为 0

**糖的隐藏名称：**
- 白砂糖、果葡糖浆、麦芽糖浆、蜂蜜、浓缩果汁、蔗糖、葡萄糖浆
- 配料表中这些词出现越早，糖分越高

## 常见食品陷阱

| 营销话术 | 真相 |
|---------|------|
| "无添加" | 法律上无明确定义，可能是营销噱头 |
| "零脂肪" | 可能糖分很高，总热量不一定低 |
| "无糖" | 可能用了代糖（阿斯巴甜、赤藓糖醇等） |
| "全麦" | 全麦粉比例可能很低 |
| "高蛋白" | 注意蛋白质来源和含量 |
| "天然" | 无法律定义，不意味着健康 |

## 代糖速查

| 代糖名称 | 甜度 vs 蔗糖 | 热量 | 安全性 |
|---------|-------------|------|-------|
| 赤藓糖醇 | 0.7 倍 | 几乎为 0 | 安全（可能引起腹泻） |
| 甜菊糖苷 | 200-300 倍 | 0 | 安全 |
| 阿斯巴甜 | 200 倍 | 低 | 有争议，苯丙酮尿症患者禁用 |
| 三氯蔗糖 | 600 倍 | 0 | 安全 |
| 糖精 | 300-500 倍 | 0 | 安全（后味发苦） |

## 实用清单

### 超市购物快速检查法

1. **看配料表前三位**：决定这个食品的本质
2. **看蛋白质含量**：同类食品中蛋白质越高越好
3. **看糖含量**：酸奶、饮料、麦片中的糖往往是隐形杀手
4. **看钠含量**：薯片、方便面、加工肉制品钠含量普遍偏高
5. **看份量**：营养成分表是按"每份"还是"每100g"计算的
