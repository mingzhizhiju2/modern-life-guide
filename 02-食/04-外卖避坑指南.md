# 外卖避坑指南

> **一句话核心：** 外卖的安全和品质，藏在你看不到的后厨里。

## 适用人群

- 经常点外卖的人
- 对外卖卫生有担忧的人
- 想花更少钱吃更好外卖的人

## 如何判断外卖店铺是否靠谱

### 线上检查清单

1. **看资质**：平台是否公示了《食品经营许可证》
2. **看地址**：地址是否真实存在（搜一下地图）
3. **看评分**：4.5 分以上且有 100+ 评价的店铺相对可靠
4. **看评价**：重点看差评，尤其是卫生相关的差评
5. **看门头照片**：有实体店且门头清晰的照片更可靠

### 危险信号

- 🚩 无实体店铺照片或照片明显是网图
- 🚩 评分极低（<3.5）或评分极高（>4.9）但评价数很少
- 🚩 店铺名称含"私厨""家庭作坊""小厨"等无证经营嫌疑
- 🚩 价格明显低于市场平均（如 1 元米饭、2 元可乐）
- 🚩 大量雷同好评（可能是刷单）

## 外卖品类安全度

| 品类 | 安全度 | 说明 |
|------|--------|------|
| 连锁品牌 | ⭐⭐⭐⭐⭐ | 标准化操作，相对可靠 |
| 大型商场店 | ⭐⭐⭐⭐ | 商场有统一食安管理 |
| 专做外卖的店 | ⭐⭐⭐ | 可能无堂食，后厨条件未知 |
| 家庭作坊 | ⭐⭐ | 卫生条件难保证 |
| 生冷/刺身 | ⭐⭐ | 配送过程温度难以全程控制 |

## 省钱技巧

### 平台优惠策略

| 策略 | 说明 |
|------|------|
| 凑满减 | 凑到刚好满减门槛，不要为了凑单多花钱 |
| 会员红包 | 经常点外卖可考虑开会员 |
| 天天神券 | 平台首页的限时优惠券 |
| 新用户优惠 | 换平台或换账号点 |
| 团购/拼单 | 和同事一起点，分摊配送费 |

### 时间策略

| 时间段 | 优惠力度 |
|--------|---------|
| 11:00-12:00 | 午餐高峰期，优惠少 |
| 13:00-14:00 | 部分商家有下午茶折扣 |
| 17:00-18:00 | 晚餐高峰期，优惠少 |
| 21:00 后 | 夜宵时段，很多商家有折扣 |

## 外卖安全实用建议

1. **收到后检查**：包装是否完好，食物是否异常
2. **尽快食用**：外卖放置超过 2 小时不建议再吃
3. **加热后食用**：有条件的话，用微波炉或锅加热一下
4. **注意过敏原**：备注清楚忌口，收到后确认
5. **保留证据**：出现问题拍照留证，及时投诉

## 遇到问题怎么维权

1. **拍照取证**：异物、变质、分量不足等
2. **平台投诉**：在外卖平台内申请退款/赔偿
3. **12315 投诉**：严重的食品安全问题拨打 12315
4. **保留证据**：食物样本、包装、订单截图
