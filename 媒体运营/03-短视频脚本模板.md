# 短视频脚本模板

> **一句话核心：** 短视频的核心是"开头 3 秒抓住人，中间讲清楚，结尾让人记住"。

## 适用人群

- 想做短视频的人
- 写了脚本但拍出来没人看的人
- 想提高短视频质量的人

## 短视频结构

### 通用结构

```
开头（3秒抓人）→ 正文（15-30秒讲清楚）→ 结尾（5秒让人记住并互动）
```

### 各部分要点

| 部分 | 时长 | 目标 | 技巧 |
|------|------|------|------|
| 开头 | 0-3秒 | 让人停下来看 | 提问、悬念、反常识、痛点 |
| 正文 | 3-30秒 | 讲清楚观点 | 案例、数据、对比、演示 |
| 结尾 | 最后5秒 | 让人记住和行动 | 金句、总结、引导关注 |

## 常见脚本模板

### 模板 1：知识点型

**适用：** 一个知识点、一个技巧

```
【开头】"告诉你一个99%的人都不知道的XX技巧"
【正文】"平时我们在XX的时候，经常会遇到XX问题。其实很简单，只需要这样做："
【演示】"你看，这样是不是就好了？"
【结尾】"觉得有用的话，点个赞收藏起来吧！"
```

### 模板 2：避坑型

**适用：** 揭露消费陷阱、误区

```
【开头】"别再XXX了！我被坑了三年才知道真相"
【正文】"我以前一直以为XXX，直到有一天..."
【展开】"实际上，商家不会告诉你的是..."
【结尾】"转发给你的家人，别让他们再被坑了"
```

### 模板 3：对比型

**适用：** 产品对比、方法对比

```
【开头】"XX和XX，到底选哪个？"
【正文】"先说结论：选XX。理由有三个："
"第一..."
"第二..."
"第三..."
【结尾】"你现在知道怎么选了吧？评论区告诉我你的选择"
```

### 模板 4：清单型

**适用：** 推荐清单、检查清单

```
【开头】"XX个你一定要知道的XX"
"第一个，..."
"第二个，..."
"第三个，..."
【结尾】"收藏起来，需要的时候随时看"
```

## 视频制作

### 拍摄设备

| 设备 | 建议 |
|------|------|
| 手机 | 大多数情况下够用 |
| 补光灯 | 重要，比相机升级更有效 |
| 麦克风 | 收音很重要，比画质更重要 |
| 三脚架 | 稳定画面 |

### 剪辑工具

| 工具 | 难度 | 适合 |
|------|------|------|
| 剪映 | 低 | 快速剪辑 |
| Premiere | 高 | 专业制作 |
| Final Cut | 中 | Mac 用户 |
| 快影 | 低 | 手机剪辑 |

### 封面设计

| 要点 | 说明 |
|------|------|
| 大标题 | 3-5 个字，清晰可见 |
| 对比色 | 文字和背景对比明显 |
| 人物表情 | 夸张、有情绪 |
| 统一风格 | 系列视频保持统一 |

## 平台特点

| 平台 | 时长 | 风格 | 推荐内容 |
|------|------|------|---------|
| 抖音 | 15-60秒 | 快节奏、娱乐化 | 知识点、技巧、避坑 |
| B站 | 3-10分钟 | 深度、专业 | 知识科普、深度分析 |
| 视频号 | 1-3分钟 | 社交传播 | 实用技巧、生活经验 |
| 小红书 | 1-3分钟 | 精致、实用 | 好物分享、避坑指南 |
