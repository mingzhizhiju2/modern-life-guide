# 多平台分发策略

> **一句话核心：** 一份内容，多平台分发，但要根据平台特点调整呈现方式。

## 适用人群

- 负责多平台运营的人
- 想最大化内容传播效果的人
- 时间有限、想提高效率的人

## 平台特点对比

| 平台 | 核心用户 | 内容偏好 | 最佳发布时间 | 分发策略 |
|------|---------|---------|-------------|---------|
| 公众号 | 25-45岁 | 深度阅读、长文 | 8-9am、8-10pm | 首发、深度 |
| 知乎 | 22-35岁 | 知识性、专业 | 7-9pm | 问答、专栏 |
| 小红书 | 20-35岁女性 | 实用、精致 | 7-9am、8-10pm | 干货、清单 |
| 抖音 | 18-40岁 | 娱乐、轻松 | 12-1pm、7-9pm | 短视频 |
| B站 | 18-30岁 | 知识、深度 | 7-10pm | 中长视频 |
| 视频号 | 30-55岁 | 生活、情感 | 7-9am、8-10pm | 社交传播 |

## 内容改编策略

### 一鱼多吃

```
知识库（MD文件）
   ↓
公众号文章（深度扩展）
   ↓
知乎回答（适配问答形式）
   ↓
小红书笔记（精简配图）
   ↓
短视频脚本（转化为视频）
```

### 不同平台的内容改编

| 原始内容 | 公众号 | 小红书 | 短视频 |
|---------|--------|--------|--------|
| 面料选购指南（3000字） | 全文发布 | 提取"3分钟看懂面料标签" | 每个面料类型一条 |
| 租房避坑指南（4000字） | 全文发布 | "租房必看的10个检查项" | 看房时的一个检查技巧 |
| 配料表解读（3500字） | 全文发布 | "3个诀窍看懂配料表" | 一个配料表陷阱 |

## 分发流程

### 标准化流程

```
周一：公众号发布（深度文章）
周二：公众号文章 → 改编为小红书笔记
周三：公众号文章 → 提取核心观点 → 知乎回答
周四：上一条内容的短视频脚本 → 拍摄 → 剪辑
周五：短视频全平台发布
周末：数据复盘，收集评论
```

## 自动化与效率提升

### 批量生产

1. 集中选题：一次性确定 1-2 周的选题
2. 批量写作：集中写 2-3 篇文章
3. 统一排版：用模板快速排版
4. 定时发布：利用定时发布功能

### 内容复用

- 同一篇文章 → 不同平台的不同版本
- 同一系列 → 连续的短视频（每个视频讲一个点）
- 用户评论 → 新的内容选题
- 老内容 → 更新数据后重新发布
