# 公众号写作指南

> **一句话核心：** 公众号文章的目标是"让读者读完且有收获"。

## 适用人群

- 负责公众号运营的人
- 想写公众号但不知道怎么写的人
- 想提高文章质量的人

## 文章结构

### 标准结构

```
标题 → 导语 → 正文（分节） → 总结 → 互动/引导
```

### 各部分要点

| 部分 | 要点 | 示例 |
|------|------|------|
| 标题 | 吸引点击，但不做标题党 | "看懂配料表，少花一半冤枉钱" |
| 导语 | 一句话说清本文价值 | "每次买食品都看不懂配料表？这篇文章帮你彻底搞懂。" |
| 正文 | 逻辑清晰、层次分明 | 分节、小标题、列表 |
| 总结 | 回顾核心观点 | "总结一下：1. 配料表按含量排序 2. 前三位决定本质 3. 注意隐藏的糖和盐" |
| 互动 | 引导评论和分享 | "你买食品时最关注什么？评论区聊聊" |

## 写作技巧

### 让文章好读

| 技巧 | 说明 |
|------|------|
| 短段落 | 每段不超过 5 行 |
| 多分段 | 不要大段文字 |
| 小标题 | 每 2-3 段一个小标题 |
| 加粗重点 | 关键词句加粗，方便扫读 |
| 列表 | 清单类内容用列表 |
| 配图 | 每 300-500 字配一张图 |

### 通俗化表达

| 原则 | 反例 | 正例 |
|------|------|------|
| 用短句 | "该产品的有效成分含量不足以产生预期效果" | "这个产品有效成分太少，没用" |
| 用比喻 | "反式脂肪酸会提高 LDL 胆固醇水平" | "反式脂肪酸就像给血管里灌水泥" |
| 用例子 | "配料表按含量排序" | "比如一瓶果汁，第一位是水，第二位是糖，那它本质是糖水" |
| 避免术语 | "使用前需进行过敏测试" | "用之前在耳后涂一点试试" |

## 排版规范

### 基础设置

| 项目 | 建议 |
|------|------|
| 字体大小 | 15-16px |
| 行间距 | 1.75-2 倍 |
| 字间距 | 1-2px |
| 页边距 | 10-15px |
| 颜色 | 正文深灰 #333，标题黑色 #000 |
| 图片 | 居中，大小统一 |

### 排版工具

- 135 编辑器
- 秀米
- 壹伴
- 直接公众号后台（简单排版）

## 公众号运营

### 涨粉策略

| 策略 | 说明 |
|------|------|
| 内容质量 | 最好的涨粉方式 |
| 互推 | 和同类公众号互推 |
| 社群 | 建立读者群 |
| 多平台引流 | 从知乎、B站、抖音引流 |
| 关键词回复 | 设置"关注后回复XX"领取资料 |

### 数据分析

| 指标 | 说明 | 优化方向 |
|------|------|---------|
| 阅读量 | 文章被看了多少次 | 标题优化 |
| 转发率 | 转发到朋友圈的比例 | 内容质量 |
| 收藏率 | 被收藏的比例 | 实用性 |
| 完读率 | 读完文章的比例 | 内容质量 |
| 新增关注 | 文章带来的新粉丝 | 内容价值 |
