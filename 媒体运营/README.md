## 运营策略

### 公众号
- 定位：深度阅读、长文发布
- 频率：每周 2-3 篇
- 内容：从模块中选取主题，做深度扩展

### 短视频
- 定位：快速获取、碎片化阅读
- 频率：每周 1-2 条
- 内容：单一知识点、实用技巧、避坑指南

## 核心原则

- **内容为王**：优质内容永远是最好的传播
- **跨平台联动**：公众号深度 + 短视频传播
- **用户参与**：引导读者贡献内容、反馈意见
- **持续迭代**：根据数据反馈优化内容策略
