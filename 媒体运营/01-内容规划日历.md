# 内容规划日历

> **一句话核心：** 好的内容规划 = 固定节奏 + 灵活选题 + 提前准备。

## 适用人群

- 负责内容运营的人
- 想做公众号/短视频但不知道发什么的人
- 想建立内容生产节奏的人

## 内容规划原则

### 内容矩阵

| 类型 | 占比 | 目的 | 示例 |
|------|------|------|------|
| 实用指南 | 40% | 解决具体问题 | 如何看懂配料表 |
| 避坑科普 | 25% | 帮助避免消费陷阱 | 租房必看的 10 个坑 |
| 观念启发 | 20% | 建立正确观念 | 为什么说"防晒是护肤最重要的一步" |
| 互动讨论 | 15% | 增加用户参与 | 你觉得什么消费最不值？ |

### 选题来源

| 来源 | 说明 |
|------|------|
| 模块内容 | 从现有模块中提取主题 |
| 用户提问 | 从评论、私信中收集问题 |
| 热门话题 | 结合社会热点做内容 |
| 行业动态 | 新政策、新标准的解读 |
| 用户投稿 | 邀请用户分享经验 |

## 内容生产流程

```
选题 → 资料收集 → 初稿 → 审核 → 排版/剪辑 → 发布 → 数据分析
```

### 时间分配

| 阶段 | 公众号 | 短视频 |
|------|--------|--------|
| 选题 | 提前 2 周 | 提前 1 周 |
| 资料收集 | 提前 1 周 | 提前 3 天 |
| 初稿 | 提前 5 天 | 提前 2 天 |
| 审核 | 提前 3 天 | 提前 1 天 |
| 制作 | 提前 1 天 | 提前 1 天 |
| 发布 | 确定时间 | 确定时间 |
| 数据分析 | 发布后 1 天 | 发布后 1 天 |
