# 搬家攻略

> **一句话核心：** 搬家 90% 的工作量在打包，剩下 10% 才是搬运。

## 适用人群

- 即将搬家的人
- 想减少搬家麻烦的人
- 第一次搬家的人

## 搬家流程

### 倒计时计划

| 时间 | 任务 |
|------|------|
| 提前 4 周 | 确定搬家日期、比较搬家公司 |
| 提前 3 周 | 开始断舍离（处理不需要的东西） |
| 提前 2 周 | 购买打包材料、开始打包非必需品 |
| 提前 1 周 | 打包大部分物品、通知物业/快递地址变更 |
| 提前 1 天 | 打包最后一批物品、清洁旧居 |
| 搬家当天 | 搬运、清点、验收 |
| 搬家后 1 周 | 整理、确认地址变更生效 |

## 打包技巧

### 打包材料清单

| 材料 | 用途 | 预算 |
|------|------|------|
| 纸箱（50×40×40cm） | 通用物品 | 5-10 元/个 |
| 衣物袋/编织袋 | 衣物、被子 | 5-15 元/个 |
| 气泡膜 | 易碎品 | 20-30 元/卷 |
| 保鲜膜 | 小件、化妆品 | 10 元/卷 |
| 胶带 | 封箱 | 5-10 元/卷 |
| 记号笔 | 标注箱号 | 5 元/支 |

### 分类打包

| 类别 | 打包方法 | 标注颜色 |
|------|---------|---------|
| 衣物 | 装入编织袋，压缩袋节省空间 | 蓝色 |
| 书籍 | 小箱装，不要装太满 | 绿色 |
| 厨房用品 | 碗碟用气泡膜间隔，竖放 | 红色 |
| 易碎品 | 气泡膜包裹，箱外标注"易碎" | 红色 |
| 电子产品 | 原包装最好，否则用气泡膜+填充物 | 黄色 |
| 重要文件 | 随身携带，不要托运 | 随身 |

### 标记系统

- **箱号**：每个箱子编号（1/20、2/20……）
- **内容**：简单描述物品类别
- **房间**：搬到新家后的归属房间
- **易碎**：红色醒目标注
- **清单**：全部箱子列清单，到新家核对

## 搬家公司选择

### 搬家公司类型

| 类型 | 优点 | 缺点 | 参考价格 |
|------|------|------|---------|
| 大型搬家公司（如货拉拉） | 标准化、有保险 | 价格高 | 500-2000 元 |
| 小型搬家公司 | 灵活、便宜 | 服务参差不齐 | 300-1000 元 |
| 搬家 APP（如蓝犀牛、快狗打车） | 透明、可评价 | 高峰期加价 | 300-1500 元 |
| 自己租车 | 最便宜 | 最累、需帮手 | 100-300 元 |

### 价格构成

| 项目 | 说明 |
|------|------|
| 基本费用 | 包含一定里程和车型 |
| 超里程费 | 超出基本里程后按公里计费 |
| 楼层费 | 无电梯按楼层加收 |
| 大件费 | 钢琴、冰箱、保险柜等大件额外收费 |
| 拆装费 | 家具拆装费用 |
| 停车费 | 产生的停车费由客户承担 |
| 高速费 | 产生的过路费由客户承担 |

### 签约前确认

1. 总价是否包含所有费用
2. 是否有隐藏费用
3. 是否提供包装材料
4. 是否提供拆装服务
5. 是否提供保险
6. 如果物品损坏如何赔偿

## 地址变更清单

搬家后需要变更地址的地方：

- [ ] 身份证（异地需要回户籍地）
- [ ] 驾照
- [ ] 银行卡/信用卡账单地址
- [ ] 快递默认地址
- [ ] 外卖默认地址
- [ ] 网购平台默认地址
- [ ] 公司 HR（更新通讯录）
- [ ] 社保/公积金
- [ ] 宽带/网络
- [ ] 水电气（如果之前是自己交）
- [ ] 物业费
- [ ] 订阅服务（如杂志、会员）
- [ ] 车辆登记（如果买了车）
