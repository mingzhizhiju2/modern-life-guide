# 出行应急与安全

> **一句话核心：** 安全意识不是胆小，而是对自己负责。

## 适用人群

- 经常独自出行的人
- 夜间出行较多的人
- 有安全意识但不知道具体怎么做的人

## 日常出行安全

### 夜间出行

| 场景 | 建议 |
|------|------|
| 步行 | 走大路、不走小巷，不要戴耳机 |
| 打车 | 确认车牌和平台信息一致，分享行程给家人 |
| 公交/地铁 | 在人多的地方等车，坐靠近司机的位置 |
| 骑行 | 穿戴反光装备，骑车灯 |

### 随身物品防丢

- 手机、钱包放内袋，不放在外衣口袋
- 背包背前面（尤其在人多的地方）
- 证件和现金分开放
- 不要把手机放在桌上（餐馆）

## 应急工具

### 建议随身携带

| 工具 | 用途 | 注意 |
|------|------|------|
| 充电宝 | 手机没电时联系外界 | 10000mAh 够用 |
| 哨子 | 呼救 | 小、不占地方 |
| 创可贴 | 小伤口 | 随身带几片 |
| 纸巾/湿巾 | 清洁 | 必备 |
| 身份证复印件 | 证件丢失时应急 | 和原件分开放 |

### 建议放在包里（非随身）

- 手电筒（手机可替代，但专用手电更亮）
- 多功能刀具（注意公共交通不能带）
- 防水袋
- 急救包
- 压缩饼干（长途出行）

## 交通事故应急

### 发生事故后的步骤

1. **确保安全**：开启双闪，放置三角警示牌
2. **检查伤亡**：有人受伤立即打 120
3. **报警**：打 122（交通事故报警）
4. **拍照留证**：全景、碰撞点、刹车痕迹、车牌
5. **不要私了**：除非是极其轻微的小刮擦
6. **联系保险**：48 小时内报案

### 预防措施

- 系安全带（前后排都要）
- 不酒驾、不疲劳驾驶
- 定期检查车况（轮胎、刹车、灯光）
- 保持车距

## 自然灾害应急

| 灾害 | 应对方法 |
|------|---------|
| 地震 | 蹲下、掩护、抓牢，不要使用电梯 |
| 暴雨/洪水 | 向高处转移，不要涉水行走 |
| 台风 | 待在室内，远离窗户 |
| 暴雪 | 待在室内，准备好食物和水 |
| 雷电 | 远离高地、大树、金属物体 |

## 紧急联系方式

| 号码 | 用途 |
|------|------|
| 110 | 报警 |
| 119 | 火警 |
| 120 | 急救 |
| 122 | 交通事故 |
| 12345 | 市民服务热线 |
