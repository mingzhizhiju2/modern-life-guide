# 交通工具选购

> **一句话核心：** 交通工具的选购，核心是"使用场景 × 使用频率"。

## 适用人群

- 正在选购电动车/自行车/汽车的人
- 在不同交通工具之间犹豫的人
- 预算有限、想买性价比最高的人

## 电动自行车选购

### 新国标要点

根据《电动自行车安全技术规范》（GB 17761-2018）：

| 项目 | 标准 |
|------|------|
| 最高时速 | ≤25km/h |
| 整车重量 | ≤55kg（含电池） |
| 电池电压 | ≤48V |
| 电机功率 | ≤400W |
| 脚踏骑行 | 必须配备 |
| 是否需要驾照 | 不需要 |

### 选购要点

| 参数 | 说明 | 建议 |
|------|------|------|
| 电池类型 | 铅酸 vs 锂电池 | 锂电池（轻、寿命长、贵） |
| 续航 | 实际续航 = 标称 × 70% | 每天通勤距离 × 2 |
| 刹车 | 鼓刹 vs 碟刹 | 碟刹（制动好、贵） |
| 品牌 | 雅迪、爱玛、台铃、九号 | 大品牌售后有保障 |

### 价格参考

| 价位 | 配置 | 适合人群 |
|------|------|---------|
| 1000-2000 元 | 基础款、铅酸电池 | 短途代步 |
| 2000-3500 元 | 锂电池、续航 40-60km | 日常通勤 |
| 3500-5000 元 | 智能功能、长续航 | 长途通勤、追求品质 |
| 5000 元+ | 高端品牌、高续航 | 发烧友 |

## 自行车选购

### 不同类型

| 类型 | 用途 | 价格 | 适合人群 |
|------|------|------|---------|
| 城市通勤车 | 日常代步、买菜 | 500-3000 元 | 短途通勤 |
| 山地车 | 城市+轻度越野 | 1000-5000 元 | 运动+通勤 |
| 公路车 | 竞速、长距离骑行 | 2000-20000 元 | 运动爱好者 |
| 折叠车 | 通勤+地铁接驳 | 1000-5000 元 | 混合通勤 |
| 共享单车 | 偶尔使用 | 月卡 10-20 元 | 不常骑的人 |

### 选购要点

1. **车架尺寸**：根据身高选择，车架不合适骑起来很累
2. **变速系统**：Shimano、SRAM 是大品牌，入门级 7-21 速够用
3. **刹车**：碟刹优于 V 刹（雨天制动好）
4. **配件**：头盔、车灯、锁具是必备

## 汽车选购

### 购车决策框架

```
总预算 = 裸车价 + 购置税 + 保险 + 上牌费 + 油费/电费 × 年
```

| 问题 | 自问 |
|------|------|
| 年度预算 | 能承受总车价的 10-15% 作为年使用成本吗？ |
| 使用场景 | 主要是通勤、长途、还是家庭用车？ |
| 燃油 vs 新能源 | 有充电条件吗？每年开多少公里？ |
| 新车 vs 二手车 | 能接受二手车的不确定性吗？ |

### 油车 vs 电车

| 对比项 | 燃油车 | 纯电车 | 混动 |
|-------|--------|--------|------|
| 购车成本 | 低 | 高 | 中高 |
| 使用成本 | 高（油费） | 低（电费） | 中 |
| 续航 | 无焦虑 | 有焦虑 | 无焦虑 |
| 保养 | 复杂、贵 | 简单、便宜 | 中 |
| 保值率 | 稳定 | 目前较低 | 中 |
| 环保 | 差 | 好 | 中 |

### 二手车选购

1. **查维保记录**：4S 店可查，看事故维修历史
2. **查出险记录**：保险公司的出险记录
3. **第三方检测**：花 300-500 元找独立检测机构
4. **试驾**：感受变速箱、刹车、异响
5. **不要买**：事故车、泡水车、火烧车
