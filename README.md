> 在信息过载的时代，帮你找回选择的主动权。

---

## 📖 关于本项目

自从中国加入世贸组织以来，商品种类呈爆炸式增长。在广告的狂轰滥炸和虚假宣传的迷雾之下，普通消费者往往难以做出真正适合自己的选择。

**现代生活指南** 是一个开源、公益、众包的生活决策知识库。它不依赖任何商业利益，不推荐任何付费产品，只提供基于公开信息和真实体验的理性参考。

**我们的目标：** 覆盖生活中的衣食住行全方位，为不同需求、不同预算的人提供匹配的决策方案，而不是"最好的"或"最贵的"。
