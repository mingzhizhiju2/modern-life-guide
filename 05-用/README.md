## 核心原则

- **需求驱动**：先想清楚"我要用它做什么"，再决定买什么
- **参数判断**：不看广告看参数，不听话术看评测
- **够用就好**：多花 50% 的钱买 10% 的性能提升，通常不值得
- **长期成本**：便宜但两年就坏，不如贵但用五年
