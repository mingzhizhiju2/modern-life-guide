# 礼品选择指南

> **一句话核心：** 好礼物的标准不是价格，而是"对方是否真的需要和喜欢"。

## 适用人群

- 不知道送什么礼物的人
- 预算有限又想送到心坎上的人
- 想要避免送礼踩雷的人

## 送礼原则

### 黄金法则

1. **投其所好**：根据对方的兴趣和需求选礼物
2. **适度消费**：礼物价格在对方心理预期范围内
3. **实用优先**：除非对方明确表示喜欢装饰品
4. **包装用心**：好的包装让礼物价值翻倍

### 送礼黑名单

- 🚫 大件物品（关系不够亲密时）
- 🚫 宠物（除非对方明确表示想要）
- 🚫 健身/减肥相关（容易被误解为"你胖了"）
- 🚫 过于私密的物品（内衣、香水等）
- 🚫 自制的尴尬物品（除非你有特殊技能）

## 不同场景的送礼方案

### 生日礼物

| 关系 | 预算 | 推荐礼物 |
|------|------|---------|
| 普通朋友 | 100-300 元 | 书、绿植、零食礼盒、电影票 |
| 好朋友 | 300-800 元 | 蓝牙耳机、香薰机、品质文具 |
| 伴侣 | 500-2000 元 | 首饰、电子产品、旅行体验 |
| 长辈 | 300-1000 元 | 保健品、茶叶、保暖用品 |
| 领导 | 根据公司规定 | 茶叶、书、办公用品（注意合规） |

### 节日礼物

| 节日 | 推荐礼物 | 禁忌 |
|------|---------|------|
| 春节 | 水果、坚果礼盒、保健品 | 单数（不吉利） |
| 中秋节 | 月饼、茶叶、酒 | 注意对方饮食禁忌 |
| 情人节 | 鲜花、巧克力、首饰 | 过于便宜的大件 |
| 教师节 | 鲜花、笔记本、护手霜 | 贵重礼物（老师不能收） |

### 特殊场合

| 场合 | 推荐礼物 |
|------|---------|
| 乔迁 | 绿植、餐具套装、家居服 |
| 结婚 | 红包、家电、家居装饰 |
| 生子 | 婴儿用品、尿不湿礼盒 |
| 毕业 | 钢笔、笔记本、职业装 |
| 探病 | 水果、鲜花、书 |

## 送礼技巧

### 包装

- 好的包装让 100 元的礼物看起来值 200 元
- 注意颜色搭配，避免过于花哨
- 附上贺卡，写上祝福语

### 送礼时机

- 提前准备，不要临时买
- 私下送比当众送更得体
- 结婚/生子等大场合，提前送比当天送好

### 预算控制

| 关系 | 预算建议 |
|------|---------|
| 同事 | 100-300 元 |
| 普通朋友 | 100-500 元 |
| 好朋友 | 300-1000 元 |
| 伴侣 | 500-2000+ 元 |
| 家人 | 300-1000 元 |
