# 数码产品选购

> **一句话核心：** 数码产品没有"最好的"，只有"最适合你的场景的"。

## 适用人群

- 正在选购手机/电脑/平板的人
- 被参数和营销话术迷惑的人
- 预算有限、想买性价比最高的人

## 手机选购

### 需求分类

| 需求类型 | 关键参数 | 推荐价位 |
|---------|---------|---------|
| 日常使用（微信、视频、拍照） | 系统流畅、续航好、拍照够用 | 2000-4000 元 |
| 游戏爱好者 | 处理器强、散热好、高刷屏 | 3000-6000 元 |
| 摄影爱好者 | 影像系统、算法、RAW 输出 | 4000-9000 元 |
| 商务人士 | 续航、信号、轻薄 | 4000-8000 元 |
| 预算有限 | 芯片够用、内存大 | 1000-2000 元 |

### 参数解读

| 参数 | 说明 | 建议 |
|------|------|------|
| 处理器（SoC） | 决定运行速度 | 骁龙 8 系/天玑 9000 系/A 系列 ≥ 日常够用 |
| 运行内存（RAM） | 决定多任务能力 | 8GB 起步，12GB 推荐 |
| 存储（ROM） | 决定能装多少东西 | 128GB 起步，256GB 推荐 |
| 屏幕 | 分辨率、刷新率、亮度 | 1080P+120Hz 够用 |
| 电池 | 续航 | 4500mAh+，快充 65W+ |
| 摄像头 | 主摄最重要 | 不只看像素，看传感器尺寸 |

### 华为 vs 苹果 vs 安卓（三星/小米/OPPO/vivo 等）

| 对比项 | 苹果 | 华为 | 其他安卓 |
|-------|------|------|---------|
| 系统 | iOS | 鸿蒙 | Android |
| 生态 | 完善 | 较完善 | 各品牌不同 |
| 拍照 | 真实 | 综合强 | 各有特色 |
| 信号 | 一般 | 强 | 中等 |
| 保值 | 高 | 高 | 中 |

## 电脑选购

### 笔记本 vs 台式机

| 对比项 | 笔记本 | 台式机 |
|-------|--------|--------|
| 便携性 | 高 | 无 |
| 性能 | 受散热限制 | 可以很强 |
| 扩展性 | 差 | 好 |
| 性价比 | 低 | 高 |
| 维修 | 难 | 容易 |

### 笔记本选购

| 需求 | 推荐配置 | 参考价位 |
|------|---------|---------|
| 办公/学习 | i5/R5 + 16GB + 512GB | 4000-6000 元 |
| 编程/设计 | i7/R7 + 16/32GB + 1TB | 6000-10000 元 |
| 视频剪辑 | 独显（RTX 4060+）+ 32GB | 8000-15000 元 |
| 3A 游戏 | 独显（RTX 4070+）+ 32GB | 9000-20000 元 |
| 轻薄便携 | 核显、1.5kg 以下 | 5000-10000 元 |

## 耳机选购

| 类型 | 优点 | 缺点 | 适合场景 |
|------|------|------|---------|
| 入耳式 TWS | 方便、降噪 | 音质上限低 | 通勤、运动 |
| 头戴式 | 音质好、降噪强 | 体积大、热 | 办公、在家 |
| 有线 HiFi | 音质最好 | 有线的束缚 | 音乐发烧友 |
| 骨传导 | 开放耳道、安全 | 音质一般 | 运动、户外 |

## 常见陷阱

1. **"买新不买旧"**：上一代旗舰往往比同价位中端机更香
2. **"参数越高越好"**：1 亿像素手机不一定比 5000 万像素拍得好
3. **"原装线/充电器"**：第三方非认证配件可能损坏设备
4. **"延保"**：自营平台延保相对靠谱，第三方延保水深
