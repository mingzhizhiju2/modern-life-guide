## 核心原则

- **需求优先**：先明确你的生活场景，再决定买什么
- **面料＞款式**：日常穿着，面料舒适度比款式更重要
- **耐久＞廉价**：一件好衣服穿三年，比三件差衣服穿半年更省钱
- **合身＞品牌**：不合身的大牌不如合身的平价

## 贡献方向

- 补充各类面料的国家标准（GB/T 标识）
- 增加不同城市的通勤穿搭案例
- 增加童装、孕装的选购指南
