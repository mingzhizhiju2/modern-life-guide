# 面料安全类别速查：A 类、B 类、C 类到底有什么区别？

![封面](../assets/safety-categories/cover.png)

你买过那种"外贸原单"的衣服吗？没有标签，没有成分说明，但价格便宜。

你可能不知道的是：**合格的服装标签上必须标注"安全类别"——A 类、B 类、C 类——这是国家强制标准。**

没有安全类别标注的衣服，就像没有生产日期的食品——你不知道它安不安全。

---

## 安全类别是什么？

安全类别是 GB 18401-2010《国家纺织产品基本安全技术规范》规定的强制性分类标准。所有在中国销售的服装，必须标注安全类别，否则属于不合格产品。

这个标准从三个维度控制服装的安全性：甲醛含量、pH 值、色牢度。

---

## 三类标准的核心区别

**A 类（婴幼儿用品）**——甲醛含量 ≤ 20 mg/kg。这是最严格的安全等级，甲醛上限仅为 C 类的 1/15。婴幼儿的皮肤屏障功能弱，所以需要最高标准。婴幼儿服装必须标注 A 类，否则不能销售。

**B 类（直接接触皮肤）**——甲醛含量 ≤ 75 mg/kg。内衣、T 恤、袜子、床单、毛巾这些直接接触皮肤的产品，必须选 B 类及以上。如果标注的是 C 类，说明这件衣服不适合直接接触皮肤。

**C 类（非直接接触皮肤）**——甲醛含量 ≤ 300 mg/kg。外套、夹克、羽绒服、西装、窗帘这些不直接接触皮肤的产品，C 类足够了。

**C 类不是不安全，是使用场景不需要那么高的标准。** 外套买 C 类完全正常。

---

## 快速判断

婴儿连体衣必须 A 类，标了 C 类是不合格的。纯棉 T 恤必须 B 类，标了 C 类不适合贴身穿。羽绒服标 C 类是正常的。

**真正需要警惕的是没有标注安全类别的衣服。** 甲醛超标、pH 值偏酸偏碱、色牢度不够——这些是看不到的隐患。
