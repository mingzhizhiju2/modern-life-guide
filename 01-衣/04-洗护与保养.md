# 洗护与保养

> **一句话核心：** 洗坏一件好衣服只需要一次，但正确的护理可以让它陪你很多年。

## 适用人群

- 洗坏过衣服的人
- 想要延长衣物寿命的人
- 看不懂洗衣标签的人

## 洗衣标签解读

国际通用的洗涤标签（按顺序解读）：

| 符号 | 含义 | 常见变体 |
|------|------|---------|
| 🏊 水盆 | 水洗 | 盆中数字=最高水温；手=只能手洗 |
| △ 三角形 | 漂白 | ×=不能漂白 |
| □ 正方形 | 干燥 | 竖线=悬挂晾干；横线=平铺晾干 |
| 🔥 熨斗 | 熨烫 | 点数=温度等级 |
| ○ 圆圈 | 干洗 | ×=不能干洗；字母=干洗剂类型 |

### 常见组合示例

| 标签 | 含义 |
|------|------|
| 30℃ 水洗 + 不可漂白 + 平铺晾干 + 低温熨烫 | 羊毛衫的标准护理方式 |
| 40℃ 水洗 + 可氯漂 + 转笼干燥 + 中温熨烫 | 棉质T恤的标准护理方式 |
| 只可干洗（圆圈） | 真丝西装、羊绒大衣 |

## 不同材质的护理方法

### 棉

- **洗涤**：40℃以下，深浅色分开
- **干燥**：自然晾晒，避免暴晒（会发黄）
- **熨烫**：中高温，喷水更好熨
- **注意事项**：第一次下水可能缩水 3-5%

### 羊毛/羊绒

- **洗涤**：建议手洗或干洗，使用羊毛专用洗涤剂
- **水温**：30℃以下，不要搓揉
- **干燥**：平铺晾干，**绝对不要挂晾**（会变形）
- **存放**：叠放，不要挂，放樟脑丸防虫
- **起球**：正常现象，用毛球修剪器处理

### 真丝

- **洗涤**：手洗或干洗，专用中性洗涤剂
- **水温**：30℃以下
- **干燥**：阴干，避免暴晒
- **熨烫**：低温，反面熨烫
- **注意事项**：汗渍会损伤真丝，穿后及时清洗

### 合成纤维（涤纶/尼龙）

- **洗涤**：机洗即可，水温不限
- **干燥**：自然晾干或低温烘干
- **注意事项**：怕高温，熨烫需低温

## 污渍处理指南

| 污渍类型 | 处理方法 |
|---------|---------|
| 油渍 | 立即用洗洁精涂抹，静置后清洗 |
| 咖啡/茶 | 热水冲洗 + 洗衣液搓洗 |
| 红酒 | 盐覆盖吸附，冷水冲洗 |
| 血迹 | 冷水浸泡，**绝对不用热水** |
| 墨渍 | 酒精擦拭，然后清水冲洗 |
| 汗渍 | 白醋浸泡 30 分钟再洗 |

## 衣物整理与存放

### 挂 vs 叠

| 挂放 | 叠放 |
|------|------|
| 衬衫、西装、连衣裙 | 针织衫、T恤、牛仔裤 |
| 真丝、雪纺 | 羊毛、羊绒 |
| 易皱的面料 | 弹性面料 |

### 季节性存放

- 换季衣物必须**清洗干净**后存放
- 真空压缩袋适合羽绒服、棉被
- 羊毛衣物放樟脑（但不要直接接触）
- 南方注意防潮，放置干燥剂
