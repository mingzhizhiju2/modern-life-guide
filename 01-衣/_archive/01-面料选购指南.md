# 面料选购指南

> **开篇**
>
> 市面上的衣服面料五花八门：纯棉、聚酯纤维、天丝、莫代尔、亚麻、竹纤维、冰丝……光听名字就晕了。
>
> 更让人困惑的是：**同样是"纯棉"，为什么有的穿一天就塌了，有的可以洗十年不变形？同样是运动，为什么有人穿棉质 T 恤反而更难受？**
>
> 其实，面料没有"最好的"，只有"最适合的"。

## 面料基础知识

### 面料标签怎么看？

买衣服时，标签上的纤维成分信息最重要。根据 GB/T 29862-2013《纺织品 纤维含量的标识》，标签必须标注：

- **纤维种类**：棉、聚酯纤维、羊毛、氨纶等
- **百分比含量**：棉 65%、聚酯纤维 35%
- **安全类别**：A 类（婴幼儿）、B 类（直接接触皮肤）、C 类（非直接接触皮肤）

### 面料安全类别速查

| 类别 | 甲醛含量上限 | 适用 |
|------|------------|------|
| A 类 | ≤ 20mg/kg | 婴幼儿用品 |
| B 类 | ≤ 75mg/kg | 直接接触皮肤（内衣、T恤、袜子） |
| C 类 | ≤ 300mg/kg | 非直接接触皮肤（外套、窗帘） |

> **选购要点：内衣、T 恤、袜子等贴身衣物，必须选 B 类及以上。**

## 常见面料：一句话判断

| 面料 | 一句话 |
|------|--------|
| **纯棉** | 舒服但爱皱，户外别穿，日常百搭 |
| **聚酯纤维** | 运动首选，日常穿闷，正装质感差 |
| **天丝（莱赛尔纤维）** | 棉的最佳替代品，凉感好、不皱 |
| **亚麻** | 夏天最透气，皱是它的特点不是缺点 |
| **羊毛** | 冬天保暖天花板，正装也选它 |
| **真丝** | 最亲肤最贵，娇气难打理 |
| **美利奴羊毛** | 户外和内衣的神，薄而暖、不臭 |
| **尼龙（锦纶）** | 最耐磨，瑜伽和运动服首选 |
| **莫代尔** | 比棉更软，孕妇和敏感肌首选 |
| **氨纶（莱卡）** | 不单独用，加在棉里给弹性 |

## 选购通用原则

1. **先想场景，再看面料**——"我要在什么场合、什么温度下穿"
2. **看标签不盲信广告**——面料成分写在标签上，广告里的词不一定代表真实内容
3. **贴身衣物选 B 类**——安全类别是硬指标，不容忽视
