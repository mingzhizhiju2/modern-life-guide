# 物业管理与邻里

> **一句话核心：** 物业是服务者，不是管理者——你有权要求合理的服务。

## 适用人群

- 对物业服务不满意的人
- 和邻居有矛盾的人
- 不清楚物业费包含什么服务的人

## 物业费包含什么

根据《物业管理条例》，物业费通常包括：

| 服务项目 | 说明 |
|---------|------|
| 公共区域保洁 | 楼道、大堂、电梯、公共卫生间 |
| 公共区域绿化 | 修剪、浇水、病虫害防治 |
| 公共秩序维护 | 门卫、巡逻、监控 |
| 公共设施维护 | 电梯、照明、消防、门禁 |
| 垃圾清运 | 生活垃圾收集和清运 |
| 水箱清洗 | 二次供水水箱定期清洗 |

### 不包含的服务

- 房屋内部维修（室内水管、电路、墙面等）
- 室内保洁
- 快递代收（部分物业代收是额外服务）

## 物业纠纷处理

### 常见问题及解决流程

| 问题 | 解决步骤 |
|------|---------|
| 物业费不透明 | 要求物业公示收支明细 |
| 公共设施失修 | 拍照留证，书面通知物业，限定整改期限 |
| 安保不到位 | 记录具体事件，联合业主向物业施压 |
| 停车位不足 | 要求物业公示车位分配规则 |

### 维权途径

1. **与物业沟通**：书面记录沟通内容
2. **找业委会**：由业委会出面协调
3. **向街道办/住建局投诉**：12345 市民热线
4. **法律途径**：联合业主起诉物业

### 业主委员会

业委会的职责：
- 代表业主与物业公司签订合同
- 监督物业服务质量
- 管理公共收益（广告费、停车费等）
- 决定物业费调整

> 公共收益归全体业主所有，物业不能私自占有。

## 邻里关系与纠纷

### 常见纠纷类型

| 类型 | 建议处理方式 |
|------|-------------|
| 噪音 | 先友好沟通，无效找物业调解，再无效报警 |
| 漏水 | 保留证据，找物业鉴定责任方，走保险或诉讼 |
| 宠物 | 了解小区养宠规定，找物业协调 |
| 占用公共区域 | 先沟通，无效找物业或城管 |

### 邻里相处原则

1. **先礼后兵**：能沟通解决的不要激化矛盾
2. **保留证据**：录音、照片、物业证明
3. **了解法规**：了解《民法典》中关于相邻关系的规定
4. **不要私自解决**：涉及结构安全、漏水等问题，走正规渠道
