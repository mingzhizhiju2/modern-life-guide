# 家电选购逻辑

> **一句话核心：** 家电不是越贵越好，参数才是硬道理。

## 适用人群

- 正在选购家电的人
- 被各种新功能广告迷惑的人
- 想买"够用又好"的家电的人

## 通用选购原则

1. **需求决定参数**：先明确需求，再对参数
2. **基础功能＞附加功能**：洗衣机洗得干净比能连 Wi-Fi 重要
3. **能效等级**：一级能效长期更省钱
4. **售后覆盖**：大品牌在三四线城市也有售后网点
5. **尺寸适配**：先量尺寸，再下单

## 核心家电选购指南

### 冰箱

| 参数 | 选购要点 |
|------|---------|
| 容量 | 单人 100-150L，两人 200-300L，三口之家 400L+ |
| 制冷方式 | 风冷（无霜）> 直冷（有霜） |
| 能效等级 | 一级能效优先 |
| 循环系统 | 双循环/三循环（不串味）> 单循环 |
| 品牌偏好 | 海尔、容声、美的、西门子 |

### 洗衣机

| 类型 | 优点 | 缺点 | 适合人群 |
|------|------|------|---------|
| 波轮 | 便宜、洗得快、操作简单 | 费水、伤衣物 | 预算有限、老人 |
| 滚筒 | 省水、不伤衣物、可嵌入 | 贵、时间长 | 注重衣物护理 |
| 洗烘一体 | 省空间 | 烘干容量减半、容易坏 | 空间有限、南方潮湿 |
| 洗烘分体 | 效果好 | 占地方 | 有空间、预算充足 |

### 空调

| 参数 | 选购要点 |
|------|---------|
| 匹数 | 1 匹 ≈ 10-15㎡，1.5 匹 ≈ 15-22㎡ |
| 能效比（APF） | 越高越好，新一级能效 APF ≥ 5.0 |
| 变频/定频 | 变频（省电、恒温）> 定频 |
| 类型 | 挂机（性价比高）> 柜机（大空间）> 中央空调（装修前） |

### 电视

| 参数 | 选购要点 |
|------|---------|
| 尺寸 | 观看距离 2m 选 55"，2.5m 选 65"，3m 选 75"+ |
| 分辨率 | 4K 足够，8K 溢价高且无片源 |
| 面板 | OLED > MiniLED > QLED > LED |
| 刷新率 | 60Hz 够用，120Hz 适合游戏 |
| 系统 | 开机无广告优先 |

### 油烟机

| 类型 | 优点 | 缺点 |
|------|------|------|
| 顶吸 | 吸力大、价格低 | 容易碰头、难清洁 |
| 侧吸 | 不碰头、离灶近 | 噪音大、占墙面 |
| 集成灶 | 节省空间、吸力强 | 贵、维修难 |

## 能效等级解读

| 等级 | 含义 | 建议 |
|------|------|------|
| 一级 | 最节能 | 长期使用首选 |
| 二级 | 比较节能 | 性价比之选 |
| 三级 | 达到标准 | 预算有限可选 |
| 四级/五级 | 耗能高 | 不建议购买 |

## 购买时机

| 品类 | 最佳购买时间 |
|------|-------------|
| 空调 | 冬季（淡季打折） |
| 冰箱/洗衣机 | 618、双11 |
| 电视 | 新品发布前（旧款降价） |
| 烟机灶具 | 装修旺季促销 |

## 常见陷阱

1. **"智能家电"**：连 Wi-Fi、手机控制等功能 90% 的时间用不上
2. **"进口品牌"**：很多进口品牌的中低端线是国内代工，品质和国产无异
3. **"延保服务"**：家电行业利润率低，延保本身利润极高，谨慎购买
4. **"赠品"**：送的通常是滞销品或低质品，不如折现
