## 核心原则

- **位置决定价值**：租房买房，地段都是第一要素
- **功能＞装饰**：好住比好看更重要
- **按需配置**：不要为不用的功能买单
- **合同保护**：任何口头承诺都不如白纸黑字

## 贡献方向

- 补充不同城市的租房/买房经验
- 增加独居、合租、家庭的不同需求
- 增加智能家居选购指南
