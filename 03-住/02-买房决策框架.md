# 买房决策框架

> **一句话核心：** 买房不是买"最贵的"，而是买"最适合你的"。

## 适用人群

- 考虑买房但不确定从何入手的人
- 正在看房、需要决策框架的人
- 担心买房踩坑的人

## 买房前自问清单

### 你真的需要买房吗？

| 问题 | 自我评估 |
|------|---------|
| 你打算在同一城市住 5 年以上吗？ | 是/否 |
| 你是否有稳定的收入覆盖月供？ | 是/否 |
| 你是否准备好了首付和税费？ | 是/否 |
| 你是否有紧急备用金（6 个月月供）？ | 是/否 |
| 你是否接受买房后生活方式的变化？ | 是/否 |

> 如果以上问题有 2 个以上为"否"，建议暂缓购房计划。

### 租房 vs 买房

| 对比项 | 租房 | 买房 |
|-------|------|------|
| 灵活性 | 高 | 低 |
| 长期成本 | 可能更高 | 可能更低 |
| 首付压力 | 无 | 大 |
| 维护成本 | 房东负责 | 自己负责 |
| 资产增值 | 无 | 有潜力 |
| 生活质量 | 受制于房东 | 自己做主 |

## 预算规划

### 实际可负担价格

```
月供 ≤ 月收入 × 30%
总价 = 首付 + 贷款
贷款额度 = 月收入 × 30% × 12 × 贷款年限 × 折现系数
```

### 买房总成本构成

| 项目 | 比例 | 说明 |
|------|------|------|
| 首付 | 20-40% | 首套 20-30%，二套 40-70% |
| 契税 | 1-3% | 首套 90㎡ 以下 1%，以上 1.5% |
| 维修基金 | 2-3% | 各地不同 |
| 个税/增值税 | 1-5.6% | 卖方承担，通常转嫁购房者 |
| 中介费 | 1-3% | 链家等大中介 2-3% |
| 装修 | 10-20 万+ | 视面积和标准 |
| 物业费 | 每年数千 | 视面积和小区档次 |

## 选房框架

### 地段优先级

```
通勤距离 > 学区 > 商业配套 > 医疗配套 > 升值潜力
```

### 户型评价

| 指标 | 好 | 一般 | 差 |
|------|-----|------|-----|
| 朝向 | 南北通透 | 朝南 | 朝北/朝西 |
| 户型 | 方正 | 稍有不规则 | 异形 |
| 采光 | 全明 | 部分暗 | 暗卫/暗厨 |
| 得房率 | >80% | 70-80% | <70% |
| 楼层 | 中间层 | 中高层 | 顶层/底层 |

### 常见户型陷阱

- **"赠送面积"**：可能是违建，无法确权
- **"入户花园"**：实际是走道，使用率低
- **"多功能房"**：实际是过道，放不下床
- **"全明设计"**：注意看窗户朝向，朝北采光差

## 看房流程

1. **线上筛选**：确定预算、区域、户型
2. **实地看房**：至少看 10-20 套做对比
3. **复看**：选定 2-3 套，不同时段看
4. **谈价**：了解近期成交价，合理出价
5. **签约**：仔细阅读合同，确认所有条款
6. **贷款**：比较不同银行利率和放款速度
7. **过户**：办理过户手续
8. **交房**：验收房屋，结清费用

## 常见误区

1. **"买房就能赚钱"**
   - 房住不炒，自住需求优先
   - 过去 20 年的增长不可复制

2. **"买大不买小"**
   - 大房子意味着更高的月供、物业费、装修费、清洁成本
   - 够用就好，多出来的空间往往是闲置

3. **"新房一定比二手房好"**
   - 二手房地段成熟、配套齐全、所见即所得
   - 新房有期房风险、配套不成熟
