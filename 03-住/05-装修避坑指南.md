# 装修避坑指南

> **一句话核心：** 装修的重点不是"装得好看"，而是"住得舒服"。

## 适用人群

- 准备装修的人
- 正在装修、被各种问题困扰的人
- 想了解装修预算和流程的人

## 装修模式对比

| 模式 | 优点 | 缺点 | 适合人群 |
|------|------|------|---------|
| 清包 | 省钱、完全可控 | 极度费时费力、需要专业知识 | 有时间、懂装修的人 |
| 半包 | 主材自己选、辅材施工方管 | 仍需投入时间、责任划分不清 | 有一定时间的人 |
| 全包 | 省心省力 | 主材选择受限、容易增项 | 没时间、预算充足的人 |
| 整装公司 | 一条龙服务 | 贵、风格固定 | 完全不想操心的人 |

## 装修流程

### 阶段一：准备（2-4 周）

1. 确定预算和风格
2. 选择装修模式
3. 找装修公司/工长（至少对比 3 家）
4. 看样板间、谈报价

### 阶段二：施工（2-4 个月）

| 工序 | 工时 | 注意事项 |
|------|------|---------|
| 拆改 | 3-7 天 | 承重墙不能动，提前报物业 |
| 水电 | 5-10 天 | 开槽布线，拍照留底 |
| 瓦工 | 10-15 天 | 防水、贴砖、勾缝 |
| 木工 | 7-14 天 | 吊顶、柜子 |
| 油漆 | 7-10 天 | 腻子、底漆、面漆 |
| 安装 | 7-14 天 | 灯具、洁具、五金 |

### 阶段三：验收（1-2 周）

1. 水电验收
2. 防水验收（闭水试验 48 小时）
3. 竣工验收
4. 空气检测（甲醛等）

## 最容易踩的坑

### 水电阶段

- **坑**：插座留少了或位置不对
  - **对策**：每个空间列好电器清单，量好家具尺寸再定插座位置
- **坑**：水管走天不走地
  - **对策**：虽贵但便于维修，推荐

### 瓦工阶段

- **坑**：瓷砖没留缝
  - **对策**：留缝 2mm，避免热胀冷缩起拱
- **坑**：美缝颜色选错
  - **对策**：中灰色万能，不要选白色（容易变黄）

### 木工阶段

- **坑**：定制柜子尺寸不对
  - **对策**：现场复尺，和设计师一起确认

### 刷漆阶段

- **坑**：颜色翻车
  - **对策**：先买小样刷在墙上，看自然光和灯光下的效果

## 省钱建议

1. **主材自己买**：瓷砖、地板、卫浴等主材自己采购，比装修公司代购便宜 20-30%
2. **不做复杂吊顶**：简单石膏线或平顶，省钱又耐看
3. **橱柜拉篮非必需品**：简单隔板 + 收纳盒更实用
4. **灯具网购**：线下灯具店溢价严重，网购便宜很多
5. **家具慢慢添**：入住后按需购买，不急于一次买齐
