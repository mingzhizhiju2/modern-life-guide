# 家居收纳系统

> **一句话核心：** 收纳不是把东西藏起来，而是让每件物品都有它的"家"。

## 适用人群

- 家里总是乱、不知道怎么整理的人
- 刚搬家需要规划收纳的人
- 想精简物品、过上更整洁生活的人

## 收纳三大原则

1. **可视化**：一眼能看到，拿取方便
2. **就近原则**：在哪里用，就放在哪里
3. **二八法则**：80% 藏起来，20% 展示出来

## 不同空间的收纳方案

### 玄关

| 问题 | 解决方案 |
|------|---------|
| 鞋子乱放 | 鞋柜按频率分区，当季鞋放便捷位置 |
| 钥匙/包包随手丢 | 设置固定"放物区"（托盘、挂钩） |
| 外套没地方挂 | 预留挂衣区，高度 1.2-1.5m |

### 厨房

| 问题 | 解决方案 |
|------|---------|
| 台面堆满 | 能上墙的上墙，能进柜的进柜 |
| 调料瓶杂乱 | 统一分装瓶，贴标签 |
| 锅具占地方 | 竖放收纳，利用橱柜拉篮 |
| 冰箱塞满 | 分区存放（冷藏=剩菜/蔬菜/蛋奶），定期清理 |

### 卧室

| 问题 | 解决方案 |
|------|---------|
| 衣柜太乱 | 按类别（上衣/下装/外套）>> 再按颜色排列 |
| 换季衣物 | 压缩袋收纳，放高处或床底 |
| 床边杂物 | 床头柜只放睡前必需品（充电器、书） |

### 卫生间

| 问题 | 解决方案 |
|------|---------|
| 洗漱台乱 | 镜柜收纳，台面只留洗手液 |
| 毛巾乱放 | 挂钩定位，一人一钩 |
| 化妆品太多 | 按使用频率分区，不常用的收起来 |

## 收纳工具选择

| 工具 | 用途 | 选购建议 |
|------|------|---------|
| 收纳盒 | 分类存放小件 | 统一尺寸，买前量好柜子尺寸 |
| 分隔板 | 抽屉内分区 | 可调节式最灵活 |
| 挂钩/挂杆 | 墙上空间利用 | 免打孔款（3M胶/吸盘） |
| 真空压缩袋 | 衣物/被子压缩 | 手动款够用，电动款省力 |
| 标签机 | 标识物品位置 | 美观实用，但非必需 |

## 断舍离指南

### 扔东西的判断标准

| 情况 | 建议 |
|------|------|
| 过去一年没穿过/用过 | 处理掉 |
| 坏了/修不好了 | 处理掉 |
| 有替代品 | 处理掉 |
| 买的时候就不喜欢 | 处理掉 |
| 觉得"以后可能会用到" | 如果一年内没用过，处理掉 |

### 不 bought 清单

- 同一功能的物品不要买第二个
- 促销时不要为了凑单而买
- 旅行纪念品非必要不买
- 网红收纳神器（很多是智商税）

## 维持整洁的习惯

1. **物归原处**：用完的东西放回原处，这是最重要的习惯
2. **台面清空**：每天睡前花 5 分钟清理台面
3. **一进一出**：买一件新东西，就处理一件旧东西
4. **定期清理**：每季度做一次断舍离
5. **不要囤货**：纸巾、洗衣液等囤货占地方，用完再买
