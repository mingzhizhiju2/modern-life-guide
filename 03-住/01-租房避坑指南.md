# 租房避坑指南

> **一句话核心：** 租房踩的坑，90% 在看房时就能发现。

## 适用人群

- 第一次租房的人
- 被中介坑过、想避坑的人
- 即将换房的人

## 找房阶段

### 渠道对比

| 渠道 | 优点 | 缺点 | 建议 |
|------|------|------|------|
| 贝壳/链家 | 房源真实、流程规范 | 中介费高（一个月租金） | 首选 |
| 自如/我爱我家 | 集中式管理、省心 | 价格偏高、服务费 | 可考虑 |
| 58同城/安居客 | 房源多 | 虚假房源多 | 需谨慎辨别 |
| 豆瓣/闲鱼 | 个人转租、无中介 | 无保障、风险高 | 仅限实地看房 |
| 小区物业 | 直租、无中介费 | 靠运气 | 可以去问 |

### 预算分配建议

| 项目 | 建议占比 | 说明 |
|------|---------|------|
| 房租 | 月收入 25-30% | 超过 30% 会影响生活质量 |
| 押金 | 通常 1-3 个月租金 | 退房时注意退还条件 |
| 中介费 | 通常 1 个月租金 | 可与中介协商 |
| 搬家费 | 500-2000 元 | 距离和物品量决定 |
| 置办费 | 2000-5000 元 | 基础家具家电 |

## 看房阶段

### 检查清单

**白天看：**
- [ ] 采光如何（最好上午和下午各看一次）
- [ ] 通风情况（开窗感受）
- [ ] 窗外视野和噪音
- [ ] 小区环境、安保

**晚上看（如果可能）：**
- [ ] 周边噪音（夜市、广场舞等）
- [ ] 照明情况
- [ ] 夜间治安

**重点检查：**
- [ ] 水压（开龙头、冲马桶）
- [ ] 空调/暖气是否正常
- [ ] 墙面有无渗水、发霉
- [ ] 门窗是否密封
- [ ] 电路是否正常
- [ ] 下水道是否通畅
- [ ] 是否有异味（下水道、隔壁）
- [ ] 手机信号（尤其是地下室）

### 危险信号

- 🚩 房租明显低于同小区均价
- 🚩 中介催促立即签约（"再不签就没了"）
- 🚩 不让晚上看房
- 🚩 小区环境脏乱差
- 🚩 邻居看起来不合适（噪音、安全等）

## 签约阶段

### 合同必看条款

| 条款 | 注意点 |
|------|--------|
| 租期 | 起止日期、续租条件 |
| 租金 | 金额、支付方式、付款周期 |
| 押金 | 金额、退还条件、扣除标准 |
| 维修责任 | 自然损耗 vs 人为损坏划分 |
| 转租 | 是否允许转租 |
| 退租 | 提前退租的违约金 |
| 物业费/取暖费 | 由谁承担 |
| 家具清单 | 清点并拍照留证 |

### 签约前必做

1. **核实房东身份**：查看房产证和身份证
2. **如果是二房东**：确认大房东是否同意转租
3. **拍照留底**：所有房间、家具、家电的现状
4. **检查水电煤气**：拍照记录初始读数
5. **确认物业费**：是否已结清

## 入住阶段

### 入住后尽快做的

1. 换锁芯（或确认房东给全钥匙）
2. 检查烟雾报警器
3. 购买租房保险（可选）
4. 办理居住证（如需）
5. 加入业主群/邻居群

## 退租注意事项

1. **提前通知**：按合同约定提前（通常 30 天）
2. **打扫干净**：但不建议深度保洁，标准是"正常使用痕迹"
3. **拍照留证**：退租时拍照，防止押金纠纷
4. **结清水电**：最后一个月账单结清
5. **核对押金**：要求房东书面说明扣款原因
