# 体检项目选择

> **一句话核心：** 体检不是越贵越好，而是越精准越好。

## 适用人群

- 每年体检但不知道查什么的人
- 想给父母安排体检的人
- 担心体检漏检或过度检查的人

## 基础体检项目

### 必查项目（成年人）

| 项目 | 频率 | 说明 |
|------|------|------|
| 血常规 | 每年 | 基础血液指标 |
| 尿常规 | 每年 | 肾脏、泌尿系统 |
| 肝功能 | 每年 | 肝脏健康 |
| 肾功能 | 每年 | 肾脏健康 |
| 血脂 | 每年 | 心血管风险 |
| 血糖 | 每年 | 糖尿病筛查 |
| 血压 | 每年 | 高血压 |
| 心电图 | 每年 | 心脏健康 |
| 胸片/CT | 每年 | 肺部疾病（吸烟者更需关注） |
| 腹部B超 | 每年 | 肝、胆、胰、脾、肾 |

### 按年龄增加

| 年龄段 | 建议增加项目 |
|--------|-------------|
| 20-30 岁 | 甲状腺功能、乙肝五项 |
| 30-40 岁 | 甲状腺B超、幽门螺杆菌、HPV（女性） |
| 40-50 岁 | 胃肠镜、乳腺钼靶（女性）、前列腺检查（男性） |
| 50-60 岁 | 骨密度、脑血管检查、肿瘤标志物 |
| 60 岁+ | 全面心脑血管检查、认知功能评估 |

### 按性别增加

| 性别 | 建议增加项目 |
|------|-------------|
| 女性 | 乳腺B超/钼靶、妇科B超、宫颈TCT+HPV、性激素六项 |
| 男性 | 前列腺B超/PSA、睾丸检查 |

## 体检套餐选择

### 避坑指南

| 项目 | 建议 | 说明 |
|------|------|------|
| 基因检测 | 不推荐 | 多数无临床指导意义 |
| 肿瘤标志物全套 | 有针对地查 | 单项异常不准，需结合其他检查 |
| 微量元素检测 | 不推荐常规 | 临床意义有限 |
| 红外热成像 | 不推荐 | 缺乏循证医学证据 |
| 经颅多普勒 | 有症状再查 | 不推荐常规筛查 |

### 套餐选择原则

1. **基础套餐 + 按需增加**，比买"豪华套餐"更合理
2. **同品牌体检机构**持续体检，便于对比历年数据
3. **三甲医院 vs 体检机构**：医院更准，机构服务更好

## 体检前注意事项

| 项目 | 准备事项 |
|------|---------|
| 空腹 | 8-12 小时不进食，可少量喝水 |
| 前一天 | 清淡饮食，不饮酒，不熬夜 |
| 女性 | 避开月经期，不做妇科检查 |
| 药物 | 降压药等长期药物正常服用 |
| 着装 | 宽松方便穿脱的衣服 |

## 体检报告解读

### 常见异常指标简易参考

| 指标 | 异常方向 | 可能原因 | 建议 |
|------|---------|---------|------|
| 血压 > 140/90 | 偏高 | 高血压 | 复查确认，生活方式干预 |
| 空腹血糖 > 6.1 | 偏高 | 糖尿病风险 | 复查，控制饮食 |
| 总胆固醇 > 5.2 | 偏高 | 高血脂 | 低脂饮食，复查 |
| 尿酸 > 420（男） | 偏高 | 高尿酸 | 控制嘌呤摄入 |
| 转氨酶（ALT）升高 | 偏高 | 肝损伤 | 戒酒，复查 |

> ⚠️ 以上仅供参考，具体诊断请咨询医生。
