# 心理健康

> **一句话核心：** 心理健康和身体健康一样重要，同样需要关注和照顾。

## 适用人群

- 感到压力大、焦虑的人
- 情绪低落、提不起劲的人
- 想了解心理健康知识的人

## 常见心理问题

### 焦虑

| 表现 | 建议 |
|------|------|
| 过度担心、坐立不安 | 深呼吸练习、正念冥想 |
| 心跳加速、出汗 | 运动、规律作息 |
| 难以集中注意力 | 减少信息摄入、番茄工作法 |
| 睡眠问题 | 改善睡眠卫生 |

**何时需要专业帮助：**
- 焦虑持续超过 2 周
- 严重影响日常生活
- 出现躯体症状（心慌、手抖等）

### 抑郁

| 表现 | 建议 |
|------|------|
| 持续情绪低落 | 寻求专业帮助 |
| 对事物失去兴趣 | 保持社交联系 |
| 精力下降、疲劳 | 适度运动 |
| 自我评价低 | 认知行为疗法 |
| 睡眠和食欲改变 | 就医评估 |

### 压力

| 压力来源 | 应对方法 |
|---------|---------|
| 工作/学业 | 时间管理、设定合理预期 |
| 人际关系 | 学习沟通技巧、设立边界 |
| 经济压力 | 制定预算、寻求财务咨询 |
| 重大变故 | 寻求支持系统、专业帮助 |

## 心理自助方法

### 正念冥想

**入门方法：**
1. 找一个安静的地方，坐直
2. 闭上眼睛，专注于呼吸
3. 注意力跑开时，温柔地拉回来
4. 从 5 分钟开始，逐渐延长

**推荐 APP：** 潮汐、Now 冥想、Headspace

### 认知行为疗法（CBT）基本原则

1. **识别负面思维**：注意"我什么都做不好"这类自动思维
2. **挑战负面思维**：有什么证据支持？有什么证据反对？
3. **替代更合理的思维**：用更平衡的视角看问题
4. **行为实验**：试试看，结果可能没有想象中那么糟

### 情绪日记

每天记录：
- 今天发生了什么？
- 我的感受是什么？（1-10 分）
- 我有什么想法？
- 我做了什么？
- 有什么更好的应对方式？
