# 医保与就医指南

> **一句话核心：** 了解医保能省很多钱，知道怎么看病能省很多时间。

## 适用人群

- 刚参加工作的年轻人
- 不清楚医保怎么用的人
- 看病不知道挂什么科的人

## 医保基础知识

### 医保类型

| 类型 | 覆盖人群 | 缴费方式 | 报销比例 |
|------|---------|---------|---------|
| 职工医保 | 在职/退休职工 | 单位和个人共同缴纳 | 较高（70-90%） |
| 城乡居民医保 | 未参加职工医保的居民 | 个人缴纳+政府补贴 | 较低（50-70%） |

### 医保报销规则

```
报销金额 = (总费用 - 起付线 - 自费部分) × 报销比例
```

| 项目 | 说明 |
|------|------|
| 起付线 | 年度内需自付的金额，超过部分才报销 |
| 封顶线 | 年度最高报销限额 |
| 自费部分 | 医保目录外的药品、检查、材料 |
| 报销比例 | 按医院等级递减（社区>一级>二级>三级） |

### 医保目录

| 类别 | 含义 | 报销情况 |
|------|------|---------|
| 甲类药品 | 临床必需、价格低 | 全额纳入报销 |
| 乙类药品 | 临床可选、价格较高 | 自付一定比例后报销 |
| 丙类药品 | 自费药品 | 不报销 |

## 就医流程

### 挂号

| 方式 | 优点 | 建议 |
|------|------|------|
| 线上挂号 | 方便、可预约 | 首选（医院APP、微信、支付宝） |
| 电话挂号 | 适合老年人 | 114 预约 |
| 现场挂号 | 抢号源 | 不适合热门专家 |

### 科室选择

| 症状 | 挂什么科 |
|------|---------|
| 发热、咳嗽、感冒 | 呼吸内科/全科 |
| 腹痛、腹泻、消化不良 | 消化内科 |
| 头痛、头晕、失眠 | 神经内科 |
| 心慌、胸闷、高血压 | 心内科 |
| 骨折、关节痛、运动损伤 | 骨科 |
| 皮肤问题 | 皮肤科 |
| 妇科问题 | 妇科 |
| 儿童问题 | 儿科 |

### 看病准备

1. **带齐材料**：身份证、医保卡、既往病历、检查报告
2. **整理症状**：什么时候开始、什么症状、什么情况下加重/缓解
3. **列出问题**：想好要问医生的问题
4. **记下用药**：目前在吃的药清单，包括中药和保健品

## 就医选择

### 医院等级

| 等级 | 特点 | 适合情况 |
|------|------|---------|
| 三级甲等 | 综合实力最强 | 疑难杂症、重大手术 |
| 二级医院 | 综合能力较好 | 常见病、慢性病 |
| 社区卫生中心 | 方便、报销比例高 | 常见小病、慢病管理 |

### 线上问诊

- **优点**：方便、省时、适合复诊
- **缺点**：不能做检查、不能开处方药
- **适合**：复诊、咨询、轻症

## 省钱技巧

1. **小病去社区医院**：报销比例高，排队少
2. **办理异地就医备案**：异地就医可以报销
3. **慢病办理门诊特殊病种**：报销比例更高
4. **检查结果互认**：30 天内同级别医院检查结果互认
5. **商业保险补充**：百万医疗险（每年几百元，覆盖大病费用）
