## 核心原则

- **预防＞治疗**：定期体检、健康生活方式比看病更有效
- **科学＞偏方**：相信循证医学，不轻信"祖传秘方"
- **适度＞极端**：极端的饮食和运动方式都不可持续
- **专业＞百度**：身体不适请咨询医生，不要自己诊断

## 贡献方向

- 补充不同年龄段（儿童、青年、中年、老年）的健康指南
- 增加常见慢性病（高血压、糖尿病等）的日常管理
- 增加中医养生指南（客观、不迷信）
