# 家庭常备药

> **一句话核心：** 家庭药箱的原则是"备急不备多"，够用就好。

## 适用人群

- 第一次配置家庭药箱的人
- 药店促销时不知道该囤什么药的人
- 有老人小孩的家庭

## 家庭药箱清单

### 必备药品

| 类别 | 药品名称 | 用途 | 注意 |
|------|---------|------|------|
| 退烧止痛 | 布洛芬、对乙酰氨基酚 | 发热、头痛、牙痛 | 二选一即可，注意不要混用 |
| 感冒药 | 氨酚黄那敏、复方感冒灵 | 感冒症状缓解 | 对症用药，不要同时吃多种 |
| 止咳化痰 | 氨溴索、右美沙芬 | 咳嗽、痰多 | 干咳和湿咳用药不同 |
| 肠胃药 | 蒙脱石散、口服补液盐 | 腹泻 | 补液盐最重要 |
| 抗过敏 | 氯雷他定、西替利嗪 | 过敏、荨麻疹 | 嗜睡程度不同 |
| 外伤 | 碘伏、创可贴、无菌纱布 | 小伤口处理 | 不要用酒精消毒伤口（太疼） |

### 按需配置

| 类别 | 药品 | 适用人群 |
|------|------|---------|
| 消化不良 | 多酶片、健胃消食片 | 经常胃胀的人 |
| 便秘 | 乳果糖、开塞露 | 便秘人群 |
| 烫伤 | 烫伤膏 | 常做饭的人 |
| 晕车 | 乘晕宁、茶苯海明 | 晕车的人 |
| 蚊虫叮咬 | 炉甘石洗剂、风油精 | 夏季 |

### 不建议常备的

- 🚫 抗生素（需要医生处方，不可自行使用）
- 🚫 中成药注射剂（风险高）
- 🚫 过期药品（定期清理）

## 用药常识

### 用药基本原则

1. **读懂说明书**：用法、用量、禁忌、不良反应
2. **不超量**：不是吃越多效果越好
3. **不混用**：不同药物可能有相互作用
4. **不重复用药**：不同品牌的感冒药可能成分相同
5. **不擅自停药**：尤其抗生素和慢性病用药

### 常见用药误区

| 误区 | 真相 |
|------|------|
| 感冒了吃抗生素 | 感冒是病毒，抗生素对病毒无效 |
| 维生素C可以预防感冒 | 不能预防，但可能缩短病程 |
| 中药没有副作用 | 中药也有副作用，且可能和西药相互作用 |
| 成人和儿童药量减半 | 儿童用药应按体重计算 |
| 止痛药会上瘾 | 布洛芬等非处方止痛药不会成瘾 |

### 服药时间

| 服药时间 | 说明 | 示例 |
|---------|------|------|
| 空腹 | 饭前 1 小时或饭后 2 小时 | 甲状腺素、部分抗生素 |
| 饭前 | 饭前 15-30 分钟 | 促胃动力药 |
| 饭后 | 饭后 15-30 分钟 | 布洛芬、阿司匹林 |
| 随餐 | 和食物一起吃 | 部分降糖药 |
| 睡前 | 睡前 30 分钟 | 安眠药、部分抗过敏药 |

## 药箱管理

| 项目 | 建议 |
|------|------|
| 存放位置 | 阴凉、干燥、避光，儿童拿不到的地方 |
| 温度 | 一般药品室温（15-25℃），部分需冷藏 |
| 定期检查 | 每 3-6 个月检查一次，过期药品及时清理 |
| 分类存放 | 内服药和外用药分开，儿童药和成人药分开 |
| 保留说明书 | 不要扔掉药品说明书 |

## 常见病自我处理

| 症状 | 建议处理 | 何时就医 |
|------|---------|---------|
| 普通感冒 | 多喝水、休息、对症用药 | 发热超过 3 天，或症状加重 |
| 腹泻 | 补液盐、蒙脱石散 | 持续超过 3 天，或伴有血便 |
| 头痛 | 布洛芬、休息 | 剧烈头痛、或持续不缓解 |
| 过敏 | 氯雷他定、远离过敏原 | 出现呼吸困难、面部肿胀 |
| 轻微烫伤 | 冷水冲洗 15 分钟 | 面积大、有水泡破溃 |
