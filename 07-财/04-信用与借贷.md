# 信用与借贷

> **一句话核心：** 信用是隐形资产，借贷是双刃剑。

## 适用人群

- 想办信用卡但不知道怎么选的人
- 有贷款需求的人
- 想了解征信的人

## 征信基础知识

### 征信报告是什么

- 记录个人信用信息的文件
- 由中国人民银行征信中心管理
- 包含：个人基本信息、信贷记录、公共记录、查询记录

### 哪些行为会影响征信

| 影响 | 行为 |
|------|------|
| 负面影响 | 逾期还款、贷款违约、信用卡套现、法院判决未执行 |
| 正面影响 | 按时还款、正常使用信用卡 |
| 无影响 | 正常查询征信（本人查询、贷后管理） |

### 如何查询征信

- **线上**：中国人民银行征信中心官网
- **线下**：人民银行分支机构、部分商业银行
- **频率**：每年免费查 2 次

## 信用卡

### 信用卡选择

| 需求 | 推荐类型 |
|------|---------|
| 日常消费 | 返现卡、积分卡 |
| 旅行 | 航空里程卡、酒店联名卡 |
| 加油 | 加油返现卡 |
| 网购 | 电商联名卡 |

### 信用卡使用注意事项

| 建议 | 说明 |
|------|------|
| 按时还款 | 设置自动还款，避免逾期 |
| 不套现 | 信用卡套现是违法行为 |
| 控制额度 | 总授信额度不超过年收入 |
| 不取现 | 取现手续费高，且无免息期 |
| 不还最低 | 最低还款利息高，年化 18%+ |

### 信用卡 vs 花呗/白条

| 对比项 | 信用卡 | 花呗/白条 |
|-------|--------|-----------|
| 免息期 | 最长 50-56 天 | 最长 40 天 |
| 权益 | 丰富（积分、返现、保险） | 较少 |
| 覆盖面 | 线上线下 | 主要线上 |
| 征信影响 | 上征信 | 花呗上征信 |

## 贷款

### 常见贷款类型

| 类型 | 利率 | 期限 | 用途 |
|------|------|------|------|
| 房贷 | 3-4% | 20-30 年 | 买房 |
| 车贷 | 3-6% | 1-5 年 | 买车 |
| 消费贷 | 4-10% | 1-5 年 | 消费 |
| 信用贷 | 5-15% | 1-3 年 | 无抵押 |
| 网贷 | 10-36%+ | 短期 | 各种 |

### 贷款决策原则

1. **能贷长的别贷短的**：房贷越长越好，对抗通胀
2. **能贷低的别贷高的**：利率越低越好
3. **能不贷的别贷**：消费贷谨慎使用
4. **算清总成本**：不只看月供，看总利息

### 房贷选择

| 类型 | 利率 | 月供 | 总利息 | 适合人群 |
|------|------|------|--------|---------|
| 等额本息 | 固定 | 每月相同 | 高 | 收入稳定 |
| 等额本金 | 递减 | 前期高后期低 | 低 | 前期还款能力强 |

## 负债管理

### 健康负债率

```
月还款额 ÷ 月收入 ≤ 30%
```

### 危险信号

- 🚩 使用信用卡取现还另一张信用卡
- 🚩 借网贷还信用卡
- 🚩 月还款额超过收入 50%
- 🚩 不知道自己的总负债是多少

### 陷入债务怎么办

1. **停止借贷**：不再借新债还旧债
2. **列出清单**：所有债务的金额、利率、还款日
3. **优先还高息**：先还利率最高的
4. **和债权人沟通**：说明情况，尝试协商还款计划
5. **寻求专业帮助**：债务咨询机构
