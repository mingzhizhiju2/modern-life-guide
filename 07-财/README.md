## 核心原则

- **先存钱，再投资**：没有储蓄，一切理财都是空谈
- **不懂不投**：不了解的产品不要碰
- **保险是保障，不是投资**：理财型保险不是最优选择
- **分散风险**：不要把鸡蛋放在一个篮子里

## 贡献方向

- 补充不同收入水平的理财方案
- 增加基金、股票、债券的具体分析
- 增加税务基础知识（个税、专项附加扣除）
