# 保险配置逻辑

> **一句话核心：** 保险不是投资，而是用小钱转移你承受不起的风险。

## 适用人群

- 想买保险但不知道买什么的人
- 被保险销售推销过但不知道是否靠谱的人
- 想给家人配置保险的人

## 保险配置原则

### 买保险的顺序

```
优先保障：医疗险 > 重疾险 > 意外险 > 寿险 > 养老/理财险
```

### 保险配置五大原则

1. **先保障后理财**：先买保障型保险，再考虑理财型
2. **先大人后小孩**：家庭经济支柱优先配置
3. **先保额后期限**：保额足够比保障时间长更重要
4. **先看条款后看公司**：保险赔不赔看条款，不看公司大小
5. **先需求后产品**：根据需求选产品，不是根据产品定需求

## 常见保险类型

### 医疗险

| 项目 | 说明 |
|------|------|
| 作用 | 报销医疗费用 |
| 典型产品 | 百万医疗险 |
| 保额 | 100-600 万 |
| 保费 | 几百元/年 |
| 建议 | 人人必备 |

### 重疾险

| 项目 | 说明 |
|------|------|
| 作用 | 确诊大病一次性赔付 |
| 保额 | 30-100 万 |
| 保费 | 3000-10000 元/年 |
| 建议 | 家庭经济支柱必备 |

### 意外险

| 项目 | 说明 |
|------|------|
| 作用 | 意外身故/伤残赔付、意外医疗报销 |
| 保额 | 50-200 万 |
| 保费 | 100-500 元/年 |
| 建议 | 人人必备，便宜 |

### 寿险

| 项目 | 说明 |
|------|------|
| 作用 | 身故/全残赔付给家人 |
| 保额 | 覆盖房贷+子女教育+家人生活费 |
| 保费 | 定期寿险较便宜 |
| 建议 | 有家庭责任的人必备 |

### 理财型保险（年金/增额终身寿）

| 项目 | 说明 |
|------|------|
| 作用 | 强制储蓄、长期增值 |
| 收益率 | 2.5-3.5%（低于基金股票） |
| 建议 | 保障型保险配齐后，有余力再考虑 |

## 不同人群的保险配置

### 刚工作的年轻人

| 保险 | 建议 | 预算 |
|------|------|------|
| 百万医疗险 | 必买 | 200-400 元/年 |
| 意外险 | 必买 | 100-200 元/年 |
| 重疾险 | 预算允许可买 | 3000-5000 元/年 |

### 家庭经济支柱（30-45 岁）

| 保险 | 建议 | 预算 |
|------|------|------|
| 百万医疗险 | 必买 | 300-800 元/年 |
| 重疾险 | 必买 | 5000-10000 元/年 |
| 意外险 | 必买 | 200-500 元/年 |
| 定期寿险 | 必买 | 1000-3000 元/年 |

### 老年人（50 岁+）

| 保险 | 建议 | 预算 |
|------|------|------|
| 惠民保/防癌医疗险 | 推荐 | 100-500 元/年 |
| 意外险 | 推荐 | 200-400 元/年 |
| 重疾险 | 不推荐（太贵） | — |

## 常见陷阱

| 陷阱 | 说明 |
|------|------|
| "返还型保险" | 有病赔钱，没病返本，但保费贵 3-5 倍 |
| "全家桶" | 一个产品包含多种保障，但每种都不足 |
| "停售炒作" | 保险产品停售是常态，不要被忽悠 |
| "小公司不安全" | 保险公司受国家监管，非常安全 |
| "健康告知随便填" | 不如实告知，理赔时可能拒赔 |

## 购买流程

1. **明确需求**：想清楚要解决什么问题
2. **了解产品**：对比 3-5 款产品
3. **仔细阅读条款**：尤其是免责条款和等待期
4. **如实告知健康**：保险公司问到的如实回答
5. **确认缴费**：确认缴费方式和周期
6. **保单管理**：整理保单，告诉家人
