# 防骗与反诈

> **一句话核心：** 不贪小便宜、不轻信"天上掉馅饼"，90% 的骗局都可以避免。

## 适用人群

- 所有人（骗局针对所有人，不分年龄和学历）

## 常见骗局类型

### 网络诈骗

| 类型 | 手法 | 识别方法 |
|------|------|---------|
| 刷单诈骗 | 先给小额返利，诱导大额刷单后跑路 | 任何要求先垫付的"兼职"都是骗局 |
| 杀猪盘 | 伪装恋爱关系，诱导投资/赌博 | 网友不提见面只谈钱 |
| 冒充客服 | 说你的快递/订单有问题，让你转账 | 官方渠道核实 |
| 钓鱼链接 | 伪装成银行/支付平台，盗取信息 | 不点陌生链接，看域名 |
| 虚假购物 | 低价商品诱导付款后不发货 | 选择正规平台交易 |

### 电信诈骗

| 类型 | 手法 | 识别方法 |
|------|------|---------|
| 冒充公检法 | 说你的银行卡涉嫌洗钱，要求转账到"安全账户" | 公检法不会电话办案 |
| 冒充熟人 | 打电话说"猜猜我是谁"，然后借钱 | 回拨原号码核实 |
| 中奖诈骗 | 说你中奖了，先交税/手续费 | 中奖不需要先交钱 |
| 养老诈骗 | 保健品、投资项目、以房养老 | 高收益的投资要警惕 |

### 线下诈骗

| 类型 | 手法 | 识别方法 |
|------|------|---------|
| 算命/祈福 | 说不破解会有灾祸 | 不信、不接话 |
| 高价卖药 | 在公园/菜市场卖"特效药" | 正规渠道买药 |
| 免费体验 | 免费体验后强制消费 | 不贪便宜 |
| 装可怜乞讨 | 说没钱吃饭/回家 | 建议找警察或救助站 |

## 防骗核心原则

### 三不原则

- **不轻信**：不轻信陌生人的话
- **不透露**：不透露身份证号、银行卡号、密码、验证码
- **不转账**：不向陌生人转账

### 六个一律

1. 接到陌生电话，只要提到银行卡，**一律挂掉**
2. 只要提到"安全账户"，**一律挂掉**
3. 陌生人发来的链接，**一律不点**
4. 陌生人发来的二维码，**一律不扫**
5. 陌生人要求屏幕共享的，**一律拒绝**
6. 陌生人要求转账的，**一律核实**

### 凡是...

- 凡是网上刷单的，都是诈骗
- 凡是网上贷款先交钱的，都是诈骗
- 凡是网友带你投资/赌博的，都是诈骗
- 凡是自称公检法要求转账的，都是诈骗
- 凡是退款/理赔要先转钱的，都是诈骗
- 凡是免费领取后要交钱的，都是诈骗

## 被骗后怎么办

### 立即行动

1. **停止转账**：如果还在操作中，立即停止
2. **报警**：拨打 110 或到最近的派出所
3. **冻结账户**：联系银行冻结账户
4. **保留证据**：聊天记录、转账记录、对方信息
5. **更改密码**：更改所有相关账户密码

### 立案流程

1. 到派出所报案
2. 提供证据材料
3. 警方决定是否立案
4. 立案后配合调查

### 心理调适

- **不要自责**：骗局设计得很专业，任何人都有可能被骗
- **不要隐瞒**：告诉家人，寻求支持
- **及时止损**：不要再试图"把损失赚回来"
- **寻求帮助**：心理压力大时寻求心理咨询

## 给家人的防骗建议

### 给父母

1. 安装国家反诈中心 APP
2. 告诉老人：要你转账的，先问子女
3. 定期检查父母的手机，卸载可疑 APP
4. 不买上门推销的任何东西
5. 不相信"免费""特效""独家"

### 给青少年

1. 不要在网上透露个人信息
2. 不要和网友单独见面
3. 不要相信"免费领皮肤/装备"
4. 遇到问题告诉父母
